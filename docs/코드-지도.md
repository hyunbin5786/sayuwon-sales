# 코드 지도

> **자동으로 만든 문서입니다. 직접 고치지 않습니다.** 코드에서 뽑아 `tools\map.ps1` 이 다시 만듭니다 (화면 · JS · CSS 파일을 더하거나 뺐을 때, 서버 동작 · DB 표를 더했을 때). 설명 글은 각 파일 맨 위 주석 첫 줄입니다 — 설명을 고치려면 그 파일의 첫 줄을 고칩니다.
