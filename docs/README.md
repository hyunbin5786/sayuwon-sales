# 문서 안내 (`docs/`)

이 폴더는 **화면마다 무엇을 어떻게 하는지 · 왜 그렇게 정했는지**를 모아 둔 곳입니다. 2026-11-25 까지는 README 한 파일(38만 자)에 모두 있었고, 그날 주제별 파일로 나눴습니다. 내용은 글자 그대로 옮겼습니다.

- 일하는 규칙 · 철칙 · DB 구조 → 저장소 맨 위 [`CLAUDE.md`](../CLAUDE.md)
- 사람이 처음 읽는 안내 → [`개발-시작하기.md`](../개발-시작하기.md)
- **어느 파일이 무엇을 하는지** → [`코드-지도.md`](코드-지도.md) (코드에서 자동으로 뽑음 · 늘 지금 코드와 같음)
- **최근에 무엇이 바뀌었는지** → [`바뀐-것-기록.md`](바뀐-것-기록.md) (고칠 때마다 여기에 한 줄)

> 화면 문서는 **그때그때 쓴 기록**입니다. 같은 화면이 여러 파일에 나뉘어 있고, 뒤에 쓴 것이 앞의 것을 바꾸기도 합니다. 그래서 아래 「화면별로 찾기」에 **그 화면에 관한 파일을 모두, 오래된 것부터** 적었습니다. **문서와 코드가 다르면 코드가 맞습니다** — 고치면서 문서도 바로잡습니다.
