# 7. 견적서 / 거래명세서 (`document/`)

> 예전 README 의 **7절** 을 그대로 옮긴 것입니다 (2026-11-25 문서 정리). 글 안의 「N절」은 [docs/README.md](../README.md) 의 「번호로 찾기」 표에서 파일을 찾습니다. 쓴 때의 설명이라 **코드와 다르면 코드가 맞습니다.**


예전 견적서&거래명세서 발행기 코드를 이 사이트로 옮긴 것입니다. 예약 정보 붙여넣기 또는 단체 화면의 견적서 · 거래명세서 버튼으로 채워지고, 사유원 · 신라철강 견적서 · 거래명세서를 PDF · 엑셀로 출력, 발급 내역을 봅니다. 헤더에 한 · 발급 내역 · 품목 관리.
- **단체 화면 견적서 · 거래명세서 버튼 ✓ → 발급 내역** (2026-11-21): 단체 화면이 견적서 사이트 공유 저장소의 발급 내역(`?history=1&limit=500`, 1분에 한 번 · 창으로 돌아올 때)을 읽어, 이 예약으로 발급한 문서가 있으면 버튼 모서리에 ✓(발급 취소한 것은 빼고). 같은 예약 = 발급할 때 남긴 예약 ID(`snapshot.intakeRec`, 단체 화면에서 열어 출력한 것부터) 또는 수신 = 업체 · 이용일 = 방문일 · 같은 문서 종류. ✓ 인 버튼을 누르면 견적서 사이트가 **발급 내역을 그 예약 것만 걸러서** 엶(「전체 보기」로 풀기) → 거기서 재발행 · 수정발행(출력 파일은 그 예약 과업에 붙음). ✓ 가 없으면 예전처럼 새로 발급. 코드: `js/group.js` `loadQuoteHist()` · `issuedDocs()` · `docBtn()`, `document.js` `histFocus` · handoff `mode:"history"`
- **단가 = 품목 관리 가격** (2026-11-17~): 전산 예약 정보를 붙여 넣어도 품목 단가는 품목 관리 가격 그대로 씁니다. 전산 상품금액 ÷ 인원은 품목 관리에 가격이 없는 품목에만 씁니다 (전산 상품금액이 예약 전체 금액으로 들어간 경우 단가가 틀리게 나왔음 · 예: 사운드워킹 107,500원). 상품금액과 다르면 「예약 정보 확인」에 경고

### 고객 견적 요청 (2026-11-21, `document/request.html` · 1단계 「고객 견적 요청」)

1. **고객 입력**: 고객님께 https://hyunbin5786.github.io/sayuwon-sales/document/request.html 주소를 보냄 (1단계의 「요청 페이지 주소 복사」). 로그인 없이 휴대폰에서 **단체명 · 담당자 성함 · 연락처 · 이메일 · 방문 희망일(필수) · 인원 · 요청사항** + 개인정보 수집 동의 → 「견적 요청 보내기」. 공유 기록 시트 `quotereq` 에 한 줄 (고객 화면은 목록을 볼 수 없음)
2. **직원 확인**: 견적서 화면 1단계(어떻게 만들까요?) 맨 위 **고객 견적 요청** 목록 (끝나지 않은 요청 · 「새 요청 n건」 · 「끝난 요청도 보기」). 요청을 누르면 선택
   - 전산 예약 정보를 붙여넣고 **자동 채우기** → 품목 · 인원 · 이용일은 예약에서, **수신 = 단체명 · 수신 담당자 = 담당자 성함**은 요청에서. 이용일 · 인원이 요청과 다르면 경고
   - 또는 **붙여넣기 없이 초안으로 시작** → 수신 · 담당자 · 이용일 · 인원 + 기본 관람(평일 · 주말) 한 줄
   - 문서 작성 중에는 위에 요청 내용(연락처 · 이메일 · 요청사항)이 보임
3. **출력 · 메일**: 출력하면 요청 상태 「접수 → 출력」. 메일 문구 창의 **받는 사람**에 고객이 적은 이메일 → 받는 사람 · 제목 · 본문은 복사 버튼으로 메일에 붙여넣기 (「메일 앱으로 열기」 버튼은 2026-11-21 없앰). 요청을 끝내려면 목록의 「끝난 요청으로」(상태 「완료」)
- 목록에서 「끝난 요청으로」 · 「요청 지우기」(시트에는 삭제 일시와 함께 남음)
- 서버: `quoteReqAdd`(로그인 없이 한 건 저장만 · 10분에 30건 넘으면 잠시 막음 · 숨은 칸으로 자동 입력 거름 · = + - @ 로 시작하는 글은 수식이 되지 않게) · `quoteReqList` · `quoteReqMark`(로그인한 직원만). **Apps Script 새 버전 배포가 필요** (배포 전에는 목록에 「새 버전으로 배포해야」 안내, 고객 화면은 「지금은 요청을 받을 수 없습니다」)
- 코드: `document/js/request.js` · `document.js` 의 「고객 견적 요청」 묶음(`loadReqs` · `reqFill` · `reqMark`) · `document.css` 끝 「고객 견적 요청」
