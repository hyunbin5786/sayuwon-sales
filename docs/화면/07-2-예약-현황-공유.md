# 7-2. 예약 현황 공유 (`status.html`, 2026-11-18)

> 예전 README 의 **7-2절** 을 그대로 옮긴 것입니다 (2026-11-25 문서 정리). 글 안의 「N절」은 [docs/README.md](../README.md) 의 「번호로 찾기」 표에서 파일을 찾습니다. 쓴 때의 설명이라 **코드와 다르면 코드가 맞습니다.**


- 고객 응대 보조 메뉴. **방문자내역 엑셀**(전산 → 방문자내역, 날짜마다 한 파일 · 여러 개를 한 번에 넣어도 됨 · 같은 날짜를 다시 넣으면 그 날짜만 새로)을 넣으면 날짜마다 공지용 표를 만듦
- 표: **구분 · 인원 · 세부 · 단체 예약 포함**
  - 구분: 오전입장(관람 9~18시) · 오후입장(관람 13~18시) · 사담 런치 1부 · 2부 · 디너 · 몽몽마방 사유의 밥상 · 그 밖의 상품(이름 그대로, 예: 선셋 디너)
  - 인원 = 홈페이지(엑셀의 상품 줄 인원 합) + **네이버(네이버 예약자관리 엑셀에서 · 직접 고쳐도 됨)**. 사유의 밥상(단체)는 뺌(관람 인원은 그대로)
  - 세부: 네이버가 있으면 「홈페이지 예약 n명 / 네이버 예약 n명」, 없으면 —
  - 단체 예약 포함: 할인이 「단체관람」이거나 그날 단체예약(공유 기록)과 연락처 · 이름이 맞는 예약 → 「단체명(담당자) n명」
  - 날짜 머리에 합계(홈페이지 · 네이버 확정 · 합계), 맨 위 제목 · 날짜 범위, 맨 아래 집계 기준 글
- **직접 고치기**: 왼쪽 칸에서 구분 이름 · 홈페이지 · 네이버 인원 · 단체(한 줄에 하나) · 줄 추가 · 빼기 · 날짜 빼기 · 제목 · 아래 글. 오른쪽 미리보기(사진과 같음)가 바로 바뀜. 고친 내용은 이 브라우저에 기억(`sy_status_v1`)
- **네이버 예약자관리 엑셀** (2026-11-19): 방문자내역과 함께(같이 · 따로) 넣음. 비밀번호 걸린 .xlsx 는 「네이버 엑셀 비밀번호」 칸(네이버 이관 화면과 같은 곳에 기억)으로 브라우저 안에서 풂. 계산은 네이버 이관 **2단계**와 같음: 이용일마다 상품 시작 시각으로 오전 · 오후, 인원 = 가격분류 (성인) · (학생) 수량, 환불금액 = 실결제금액이면 전액환불(뺌), 일부 환불이면 「성인취소×성인가 + 학생취소×학생가 = 환불금액」 조합만큼 뺌(관람권 가격은 네이버 이관 화면 저장값). 결과는 그 날짜 오전입장 · 오후입장 줄의 「네이버」 칸, 날짜 아래에 「예약 n건 · 전액환불 · 일부 환불 · ⚠ 확인할 것」. 방문자내역을 나중에 넣어도 기억해 둔 네이버 인원이 들어감 (`js/naverxl.js`)
- **네이버 사진으로 넣기** (2026-11-19 · 엑셀이 안 될 때): 네이버 예약 달력 화면 캡처를 Ctrl+V(또는 [네이버 사진으로 넣기]로 파일). 파란 「확정」 칸을 찾아(같은 세로줄 = 날짜, 같은 높이 = 줄) 숫자와 위쪽 날짜(「19」)를 읽음(tesseract.js · jsdelivr, 브라우저 안에서만). 확인 표에서 날짜 · 줄마다 구분(1번째 줄 오전입장 · 2번째 오후입장 · 나머지 빼기가 기본, 고른 것은 기억) · 숫자를 고친 뒤 [넣기] → 그 날짜의 「네이버」 칸 (`js/naverimg.js`)
- **네이버 엑셀 오류 → 직접 입력 팝업** (2026-11-19, `openNaverManual`): 네이버 엑셀을 읽다가 비밀번호 말고 다른 오류가 나면 팝업으로 이유와 함께 날짜마다(넣은 방문자내역 날짜 · ＋ 날짜 추가) 오전입장 · 오후입장 네이버 인원을 직접 → 「넣기」를 누르면 그 날짜의 「네이버」 칸에 (날짜 아래 「네이버 직접 입력: 오전 n명 · 오후 n명」). 비밀번호가 없거나 틀리면 예전처럼 비밀번호 칸
- **이 화면은 무조건 오늘 + 내일 2일** (2026-11-21, `keepTwo`): 날짜 표 · 네이버 인원 모두 오늘 · 내일만. 다른 날짜의 방문자내역 · 네이버 인원은 넣어도 빼고(「○ 방문자내역은 넣지 않았습니다」), 날이 바뀌면 지난 날짜는 저절로 빠짐(화면을 켜 둔 채여도 다시 그릴 때). 네이버 직접 입력 팝업도 늘 오늘 · 내일 두 줄(날짜 추가 버튼 없앰)
- **팀 공유 · 하루 동안 유지** (2026-11-21, `statusdb` · `pushShare` · `pullShare`): 예전엔 이 브라우저에만 저장. 지금은 화면 내용 전체를 공유 기록 한 줄(id `statusdb` · 통화 구분 「예약현황공유」)에 — 고치면 1.5초 뒤 올리고, 열 때 · 30초마다 · 창으로 돌아올 때 다른 사람이 고친 것을 받음(마지막에 저장한 것이 이김 · 적는 중에는 받지 않음). 날이 바뀌면 지난 날짜는 지움(지우기는 「고친 것」으로 치지 않아 다른 사람의 오늘 내용을 그대로 받음). 「모두 지우기」는 팀 모두의 화면에서 지워짐. 「모두 지우기」 옆에 「공유됨 · 시각 · 이름」
- **네이버 사진 없앰 · 비밀번호 오류도 직접 입력** (2026-11-19): 「네이버 사진」 칸(캡처 · Ctrl+V)은 없앰. 네이버 엑셀 비밀번호가 맞지 않으면 「…엑셀 비밀번호가 맞지 않습니다」 글 대신 「네이버 엑셀 오류 · 직접 입력」 팝업 (맞는 비밀번호를 넣으면 다시 읽음). 비밀번호를 아예 안 넣었으면 예전처럼 비밀번호 칸
- **「모두 지우기」는 네이버 엑셀 비밀번호 줄 오른쪽** (2026-11-19): 표 위 「표의 숫자 · 글자는 눌러서 바로 고칠 수 있고…」 안내 글은 없앰. 현황이 있을 때만 보임
- **엑셀 표 그대로 (다른 기록과 연결 안 함)** (2026-11-19): 단체예약 목록을 받지 않고(팀 비밀번호 칸 없앰) 방문자내역 엑셀만으로 — 단체 = 할인 「단체관람」이거나 10명 이상, 「단체 예약 포함」 이름 = 엑셀 성명 그대로(「산청군청(고영현)」)
- **미리보기는 스크롤 없이 한눈에** (2026-11-19, `fitPrev`): 오른쪽 미리보기를 칸 너비 · 화면 높이(고정 헤더 · 「사진으로 저장」 줄 빼고)에 맞춰 통째로 줄여 보여 줌 · 스크롤해도 오른쪽에 붙어 있음 (「사진으로 저장」은 원래 크기로 저장)
- **사진 글씨 크게** (2026-11-20): 사진(미리보기)의 표 글씨 11.5 → 15.5px, 인원 14 → 19px, 세부 · 단체 예약 포함 10.5 → 14px, 날짜 제목 · 합계 · 아래 집계 기준도 키움 (사진 너비 800px 그대로)
- **미리보기 = 사진 모양 그대로 · 가운데** (2026-11-20): 미리보기 칸 너비를 저장되는 사진(800px)을 줄인 크기에 딱 맞추고 오른쪽 칸 가운데에 (예전엔 칸이 오른쪽 끝까지 넓어 사진과 다르게 보였음)
- **10명 이상은 단체** (2026-11-19): 방문자내역 한 줄 인원(어른 + 학생, 상품 줄 합)이 10명 이상이면 단체예약에 없어도 「단체 예약 포함」에 넣음(예: 김천의료원 25명). 「사유의 밥상(단체)」 줄은 지금처럼 빼고(관람은 따로 셈) · 「(관람, 몽몽마방 사유의 밥상)」은 몽몽마방 사유의 밥상 줄로
- **네이버 사진 줄 · 여러 장** (2026-11-19): 줄은 회색 가로선으로 나눔 — 날짜 머리 아래 1번째 줄 = 전체(확인용 · 넣지 않음), 2번째 = 오전입장, 3번째 = 오후입장 (주말처럼 1번째 줄이 비어도 밀리지 않음 · 확정 칸이 없으면 0). 사진을 더 넣으면(여러 장 고르기 · Ctrl+V 여러 번) 날짜가 옆에 붙고 같은 날짜는 덮어씀 (토 · 일). 전체 ≠ 오전 + 오후면 ⚠
- **넣는 칸 간단하게** (2026-11-19): 위 칸 폭 980px까지 · 왼쪽 「엑셀 넣기」(방문자내역 · 네이버 예약자관리) · 오른쪽 「네이버 사진」 두 칸, 아래 한 줄에 네이버 엑셀 비밀번호 · 기억 · (필요할 때) 팀 비밀번호. 긴 설명은 마우스를 올리면 보이는 말풍선으로
- **2열 화면** (2026-11-19): 1열 = 넣는 칸(엑셀 · 네이버 사진 · 비밀번호 · 모두 지우기) + 날짜별 고치는 표, 2열 = 미리보기(사진과 같음 · 화면을 내려도 따라옴)와 그 위 「사진으로 저장」. 제목 칸은 없앰 — 사진 제목은 「사유원 예약 현황」 고정 (좁은 화면은 1열)
- **사진으로 저장**: 미리보기와 같은 표를 PNG(`사유원_예약현황_날짜.png`)로 내려받음 → 공지
- 엑셀은 이 브라우저 안에서만 읽음(어디에도 올리지 않음). 단체 이름은 팀 비밀번호가 있으면 공유 기록에서 가져옴
