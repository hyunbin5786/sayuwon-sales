# 대구대교구 무료입장 명부 (`clergy.html`, 2026-11-19)

> 예전 README 의 **(번호 없음) 대구대교구 무료입장 명부절** 을 그대로 옮긴 것입니다 (2026-11-25 문서 정리). 글 안의 「N절」은 [docs/README.md](../README.md) 의 「번호로 찾기」 표에서 파일을 찾습니다. 쓴 때의 설명이라 **코드와 다르면 코드가 맞습니다.**


- 천주교 대구대교구 수녀 · 신부 · 신학생 무료입장(연 2회) 명부. 메뉴 › 예약보조 › 고객 응대 보조. 로그인해야 보임
- **저장 (2026-11-23~): 서버 DB 의 `clergy` 표 — 한 줄 = 한 번 방문 (22절)**. 예전에는 공유 기록(calls)에 4만 자씩 나눠 `clergy0` · `clergy1` … 로 넣었음. **명부 내용은 이 저장소에 넣지 않음**
- 「엑셀 불러오기」: 명부 엑셀(머리줄 방문일 · 소속 · 이름 · 직책 · 연락처 · 비고 · 회차, 날짜 칸이 비면 위 줄 날짜)을 읽어 확인 팝업 뒤 명부를 그 내용으로 바꿈
- 「＋ 새로 추가」 (2026-11-21 바꿈): **방문일 · 소속 · 이름 · 직책 · 연락처**만 넣고 「저장」 (방문일은 단체 방문일 방식 칸 · 다섯 칸 모두 필요, 비고 · 회차 칸은 없앰). 저장 전에 최신 명부를 다시 받아 확인:
  - **회차**: 같은 사람(이름 + 연락처 숫자)이 그 방문일 해에 명부에 있는 수 + 1 → 저장되는 줄의 회차 칸에 「n회차」. 이미 2회 있으면(이번이 3회차 · 연 2회 넘음) 경고
  - **대구대교구 소속**: `js/clergyorg.js` 목록(대교구 누리집의 본당 164곳 · 교구 기관 · 교구에서 일하는 수도회, 2026-11-21 기준)에 있거나 명부에 이미 적힌 소속이면 통과. 「○○성당 · ○○본당 · 주교좌」 모양 · 「대구대교구 · 교구청 · 대구가톨릭대 · 신학원」 같은 말이 들어 있어도 통과. 아니면 경고 (대교구 본당 찾기 링크). 본당 · 기관이 바뀌면 `clergyorg.js` 에 더하기
  - 문제가 없으면 **확인 창 없이 바로 저장**. 경고가 있으면 팝업에 경고 문구 → 「그래도 저장」을 누르면 저장, 「취소」면 고쳐서 다시. 칸을 치는 동안에도 아래에 「2026년 n회차」 · 경고가 미리 보임
- 표: 방문일 최신순 · 이름 · 소속 · 연락처 찾기 · 「올해만」 · 올해 방문 횟수(2회면 빨강) · × 지우기(확인 팝업). 추가 · 지우기는 저장 직전 최신 명부를 다시 받아 반영, 1분마다 남이 고친 것 받아 옴
