# 25. 하루 한 번 작업: 오늘 다른 사람이 이미 했으면 경고 (2026-11-24 · `js/dailyguard.js`)

> 예전 README 의 **25절** 을 그대로 옮긴 것입니다 (2026-11-25 문서 정리). 글 안의 「N절」은 [docs/README.md](../README.md) 의 「번호로 찾기」 표에서 파일을 찾습니다. 쓴 때의 설명이라 **코드와 다르면 코드가 맞습니다.**


- 대상: **예약 현황 공유**(`status.html`) · **네이버 예약 → 사유원 전산 이관**(`naver.html`) — 같은 날 두 사람이 따로 하면 중복으로 들어감
- **기록**: 일을 시작하면 「오늘 · 이름 · 시각 · 무엇」을 남김 — 네이버 이관 = 1단계 텍스트 정리(`btnParse`) 또는 2단계 엑셀을 읽었을 때, 예약 현황 공유 = 엑셀을 넣었을 때(`readFiles`). 한 화면에서 처음 한 번만 올림 (`syDaily.mark`)
- **경고**: 화면을 열 때 오늘 기록에 **나 말고 다른 사람**(사번으로 비교)이 있으면 팝업 「⚠ 오늘 이미 다른 분이 한 작업입니다」 + 오늘 한 사람 · 시각 · 무엇 → **「메뉴로」**(첫 화면) / **「무시하고 시작하기」**(오류가 있어 다시 해야 할 때 · 팝업만 닫힘). 내가 한 것만 있으면 경고 없음 (`syDaily.guard`)
- **저장**: 공유 기록(calls) 작업마다 한 줄 — id `dailystatus` · `dailynaver`, 통화 구분 「하루작업」, 수정 기록 칸 `{date(한국 날짜), uses:[{name, emp, at, what}]}`. 날이 바뀌면 그 줄을 새로 씀 (줄이 늘지 않음 · **서버 고칠 것 없음** — 다시 붙여 넣지 않아도 됨)
- `naver.html` 은 이번에 `js/common.js` 를 처음 읽음 (로그인 · 공유 기록을 쓰려고)
- 확인 (로컬 `?mock=cf`): 테스트(T001)가 네이버 텍스트 정리 → 기록 · 김영업(T002)이 열면 팝업(「테스트 님 · 오전 9:59 (텍스트 정리)」) · 무시하고 시작하기 → 닫힘 / 김영업이 예약 현황 공유 엑셀 → 테스트가 열면 팝업 · 콘솔 오류 없음
- **멤버관리 「견적서 · 거래명세서 담당」 열 뺌** (2026-11-24): 표는 이름 · 사번 · 연락처 · 추가 · 빼기. 서버의 담당 지정(kv `role:quote`)과 그 처리 코드(`memberRole` · 고객 견적 요청을 담당자 할일로)는 그대로 — 이미 지정된 사람은 계속 담당이지만 화면에서 바꿀 수 없음
