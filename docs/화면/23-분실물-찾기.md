### 23-1. 신고자 / 습득자 · 멤버 연락처 → 습득자 자동 (2026-11-24)

### 23-3. 분실물 신고에도 사진 (2026-11-26)

- 고객이 잃어버린 물건의 사진을 보내 주는 경우가 있어, **분실물 신고 접수 · 고치기 창에도 사진 칸**(「분실물 사진」)을 둠. 위 23절의 「분실 신고 접수 = 사진 칸 없음」은 이제 틀림. **신고의 사진은 꼭이 아님** (습득은 예전대로 꼭) · 5장까지 · 찍기 · 고르기 · 빼기 모두 습득과 같은 칸 · 같은 저장 (기록에는 `photos:[{id, name}]` · 그림은 서버 그림 저장 `mentImgPut` / `mentImgGet`). 서버 코드는 바꾸지 않음
- **붙여넣기**: 접수 · 고치기 창이 열려 있을 때 복사해 둔 사진(메신저 · 화면 캡처)을 Ctrl+V 로 넣을 수 있음 — 신고 · 습득 모두 (`js/opsboard.js` `phAdd` · `paste`)
- 「분실물 신고」 표에도 **사진 칸** (있으면 첫 사진 작게 · 「+n」 · 누르면 크게 / 없으면 빈칸 — `OPS_PAGE.boards` 의 `photo` · `noPhoto`). 휴대폰 검색 카드는 예전부터 사진이 있으면 보임
- **로그인 없이 넣는 신고에는 사진 칸이 없음**: 서버 `lostAdd` 가 사진을 습득일 때만 받아서 (신고의 사진은 버림). 로그인 없이도 되게 하려면 `cloudflare/worker.js` `lostAdd` 가 신고의 `photos` 도 받게 고치고(먼저 백업) `js/lost.js` 사진 칸의 `show` 에서 `GUEST` 조건을 뺌
- 사진을 빼고 「취소」하면 목록의 기록은 그대로 (창을 열 때 사진 목록을 사본으로 — `openEdit`)
- 확인 (로컬 `?mock=1` · 로그인한 상태 · PC 폭과 375px): 사진 없이 신고 저장 · 사진 2장 고르고 1장 붙여넣어 저장 → 새로 고친 뒤 표에 미리보기 「+2」 → 다시 열어 1장 빼고 1장 더해 저장 · 습득은 사진 없이 저장 막힘 · 휴대폰 폭에서 신고 + 사진 → 검색 카드에 사진 → 눌러 다시 열기 · 콘솔 오류 없음. 로그인하지 않은 상태는 띄워 보지 않음
