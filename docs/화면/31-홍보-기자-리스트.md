# 31. 홍보 기자 리스트 (`press.html` · `js/press.js` · `css/press.css` · 2026-11-24)

> 예전 README 의 **31절** 을 그대로 옮긴 것입니다 (2026-11-25 문서 정리). 글 안의 「N절」은 [docs/README.md](../README.md) 의 「번호로 찾기」 표에서 파일을 찾습니다. 쓴 때의 설명이라 **코드와 다르면 코드가 맞습니다.**


- 메뉴 › 홍보 보조 › 홍보 기자 리스트. 로그인한 사람만
- **저장 = 서버 DB 의 `press` 표** (한 줄 = 기자 한 명: 리스트 · 구분 · 매체 · 이름 · 직위/소속 · 휴대폰 · 이메일 · 메모 · 순서 · 고친 사람/시각). 서버 동작 `pressList` · `pressSave`(있으면 고치고 없으면 더함 · 문장 하나로 여러 줄) · `pressDel`(지운 표시). 표는 서버가 처음 쓸 때 스스로 만듦. 백업(`export` · `tools/backup.ps1` · `tools/export.html`)에 `press` 표 포함. **기자 연락처는 이 저장소(GitHub)에는 넣지 않음**
- **표에서 바로 고치기**: 칸을 누르면 글자 칸 → Enter(또는 다른 칸)면 그 줄만 저장 · Esc 면 되돌림. 맨 위 **리스트 칩**(전체 · 리스트마다 수) · 구분 · 찾기 · 「같은 리스트 안 이메일 겹침만」(같은 리스트에 같은 이메일이 두 번이면 주황). 400명까지 그리고 「모두 보기」
- **＋ 기자 추가**(지금 고른 리스트 맨 위 빈 줄 → 매체 칸에 커서) · 왼쪽 체크 → **선택 삭제** · 줄 끝 × (확인 팝업) · **엑셀로 내려받기**(지금 보이는 기자)
- **엑셀 · 독스 불러오기** (여러 파일을 한 번에): 엑셀은 시트마다 「이메일 · 이름(기자명)」 머리줄을 찾아 매체 · 구분 · 직위(소속팀 · 매체 다음 빈 칸) · 휴대폰 · 이메일, 나머지 칸은 메모(「Updated: …」 등). 비어 있는 구분 · 매체는 위 줄 값(병합 칸). 머리줄이 없는 시트는 앞 시트 칸 모양으로. **ID · PW 가 있는 시트(웹하드)는 넣지 않음**. 독스(.docx)는 첫 줄 = 리스트 이름 · 글 속 이메일(뒤 괄호 = 메모). 미리 보기에서 리스트 이름 고치기 · 넣을 것 체크 — 「참고용 · 과거」 시트와 다른 명단과 이메일이 80% 이상 같은 더 작은 명단(예전 판 파일)은 처음에 체크를 빼 둠. 같은 리스트에 같은 이메일(없으면 매체 + 이름)이 있으면 건너뜀 → 다시 넣어도 겹치지 않음
- **메일 주소 복사**: 체크한 기자(없으면 지금 보이는 기자) 이메일을 「a@b.com, c@d.com, …」(받은 독스와 같은 모양 · 겹치는 주소는 한 번) → 받는 사람 · 숨은참조 칸에 붙여 넣기. **독스 모양으로 복사** = 첫 줄 리스트 이름 + 다음 줄 주소들
- **처음 한 번**: Cloudflare 에 `cloudflare/worker.js` 를 다시 붙여 넣은 뒤(`pressList` 가 생김) 이 화면에서 「엑셀 · 독스 불러오기」로 기자 리스트 파일 4개를 한꺼번에 넣음
