# 7-1. 전화응대 멘트 (`ment.html`, 2026-11-18)

> 예전 README 의 **7-1절** 을 그대로 옮긴 것입니다 (2026-11-25 문서 정리). 글 안의 「N절」은 [docs/README.md](../README.md) 의 「번호로 찾기」 표에서 파일을 찾습니다. 쓴 때의 설명이라 **코드와 다르면 코드가 맞습니다.**


- 고객 응대 보조 메뉴. 문자 · 카톡으로 보내는 안내 멘트를 모아 두고 **「복사」** 한 번으로 붙여 넣기
- 멘트마다 **이름**(화면에는 괄호 없이) + 내용. **복사** = **[이름]** 첫 줄 + 내용 (2026-11-18). 글 칸은 **높이 고정 220px**(짧으면 빈 채로 · 길면 칸 안에서 스크롤). 화면은 가로 넓게(최대 1760px) · **3열**(좁은 화면은 2열 · 1열). **☆ 즐겨찾기**를 누르면 ★ · 노란 카드로 **맨 위**에 — **멘트에 함께 저장되어 휴대폰 · 컴퓨터 · 모든 사람에게 같음**(2026-11-18, 멘트 저장 모양 `fav:true` · 예전 이 브라우저 즐겨찾기 `sy_ment_fav` 는 컴퓨터에서 열 때 한 번 옮김). **즐겨찾기 바꾸기 · 추가 · 수정 · 삭제는 컴퓨터에서 로그인한 사람만**(휴대폰은 ★만 보이고 복사만). ★를 누르면 공유 기록에 저장한 뒤 다시 읽어 확인하고 「휴대폰에도 맨 위에 보입니다」(저장 못 하면 되돌리고 팀 비밀번호 칸). **새 버전이 나오면 화면이 스스로 한 번 새로 불러옴**(브라우저가 10분까지 기억하던 예전 코드 방지) · **수정** = 그 자리에서 이름 · 내용 고치기(삭제도 여기, 확인 뒤) · 위 **「＋ 멘트 추가」** · 검색
- **순서 바꾸기** (2026-11-20): 컴퓨터에서 로그인하면 멘트 이름 앞 **⠿** 를 끌어 다른 멘트 위에 놓으면 그 자리로 (아래로 옮기면 그 멘트 뒤, 위로 옮기면 앞). 공유 기록에 저장되어 모든 사람 · 휴대폰도 같은 순서. 즐겨찾기는 늘 위에 모이므로 즐겨찾기끼리 · 나머지끼리만. 휴대폰에서는 안 보임
- **로그인 · 팀 비밀번호 없이 보고 복사 가능** (2026-11-18 · 주로 휴대폰, Apps Script `mentList` · `mentImgGet` 은 비밀번호 없이 멘트 한 줄 · 멘트 이미지만 돌려줌). **추가 · 수정 · 삭제는 로그인한 사람만**, 저장할 때만 팀 비밀번호(없으면 그때 칸이 뜸). **휴대폰(폭 700px 이하)에서는 ☆ · 제목 · 복사 버튼을 한 줄에**(제목이 길면 … · 이미지 버튼은 「이미지1」처럼 짧게 · 글 내용 · 수정 · 추가는 숨김, 데스크탑은 그대로)
- 저장: 공유 기록(calls) 한 줄 `id=mentdb` · 통화 구분 `응대멘트` · 수정 기록 칸에 `{items:[{id,title,body}], at, by}`. 브라우저에 마지막 목록을 기억(`sy_ment_cache`)해 바로 보임. 아직 아무것도 없으면 기본 멘트 [홈페이지링크]. **이 기기에서 공유 멘트를 한 번도 받지 못했으면(휴대폰 등 팀 비밀번호를 안 넣은 기기) 기본 멘트 대신 「팀 비밀번호를 넣으면 모든 멘트가 보입니다」 안내**(2026-11-18)
- **이미지** (2026-11-18): 멘트를 추가 · 수정할 때 **「＋ 이미지」(여러 장) · 붙여넣기(Ctrl+V) · 끌어다 놓기**. 긴 쪽 1600px로 줄여서 구글 드라이브 `사유원 단체예약 서류 / 응대멘트 이미지` 폴더에 (Apps Script `mentImgPut` · `mentImgGet`, 이 폴더 파일만 돌려줌). 카드에는 그림 미리보기 없이 **「글 복사」 옆에 「이미지 복사」 버튼**(여러 장이면 「이미지 1 복사」 · 「이미지 2 복사」 …, 2026-11-18). 그림은 화면을 열 때 미리 받아 둠. **휴대폰: 누르면 공유 창**(카카오톡 · 문자를 골라 그림을 바로 보냄 — 휴대폰 카톡은 붙여넣기로 그림이 잘 안 들어가서) · **컴퓨터: 클립보드에 그림 → Ctrl+V**(크롬 · 엣지: 그림 그대로 클립보드 → 카톡에 Ctrl+V). 이미지가 있는 멘트의 「복사」는 「글 복사」 — 글 붙여 넣고 → 이미지 복사 → 붙여 넣기. 멘트 저장 모양 `imgs:[{id, name}]`. **Apps Script 를 새 버전으로 배포해야 동작** (전에는 「배포 필요」 안내)
- **휴대폰: 「이미지 저장」 하나로** (2026-11-19, `saveImgs`): 휴대폰(폭 700px 이하)에서는 「이미지 복사」 버튼들 대신 「이미지 저장 (n)」 버튼 하나 → 그 멘트의 그림을 모두 저장. 안드로이드 = 내려받기(Download 폴더 → 갤러리 앱), 아이폰 · 아이패드 = 공유 창의 「이미지 n개 저장」(사진 앱). 컴퓨터는 그대로 「이미지 복사」
- 코드: `js/ment.js` (`DEFAULT` = 기본 멘트) · `css/ment.css`
