# 6. 다음날 고객 응대 준비 (`prep.html`)

- **준비할 날짜를 맨 위에** (2026-11-18): 기본 = 내일(오늘 + 1), 방문일 칸 모양(누르면 달력). 넣은 엑셀의 방문일이 이 날짜와 다르면 **「엑셀 날짜가 다릅니다」 팝업**(읽지 않음 · 「다른 파일 고르기」). 전에 읽어 둔 다른 날짜 엑셀이 남아 있어도 열 때 팝업
- **② 이름 = 「티켓 발권 대상」**(예전: 10인 이상 손님 목록) · **③ 단체예약 정보 넣기는 없애고 늘 자동 연결**(연결 요약은 ② 제목 옆, 팀 비밀번호 칸은 날짜 칸 아래)
- **팀 비밀번호 줄** (2026-11-19): 안내 · 비밀번호 칸 · 연결 버튼을 한 줄로 (좁은 폰에서만 줄바꿈)
- **④ 표 이름 칸** (2026-11-19 바꿈): 「목록」 · 「새로 조사」 표시는 없앰 — 한 줄에 모든 정보. 단체예약과 연결된 줄만 이름 옆에 돋보기 버튼(자세히 = 다음 탭에 그 단체예약 group.html?open=id)
- **단체예약은 예약확정만 연결** (2026-11-19): 예약상담 · 가예약 · 예약취소는 목록에서 가져오지 않음 (예전 이름 예약접수 · 공식예약, 관리자 사이트에서 온 예약은 확정으로 봄)
- **입장문 「예약 고정」 · 「추천」 · 「직접」 구분** (2026-11-19): 단체예약 비고 칸에 `입장문 치허문/곡신문`이 있으면 그 문으로 고정(진한 테두리 · 초록 「예약 고정」, 다시 추천해도 안 바뀜, 추천과 다르면 이유 칸에 「추천은 …」). 정해 두지 않았으면(미정 포함) 추천(점선 · 「추천」). 표에서 바꾸면 「직접」. 같은 치허문이어도 표시가 다름. 이미지로 저장에도 고정은 「치허문 · 고정」으로 표시
- **「단체명(담당자)」 이름은 단체** (2026-11-19): 방문자내역 이름이 `산청군청(고영현)` 모양이면 단체예약 목록에 없어도 개인이 아니라 단체(이름 그대로 · 「(개인)」 안 붙임). 괄호 안이 개인 · 대리면 제외- **새로 조사 줄에 색은 칠하지 않음** (2026-11-19 · 「새로 조사」 표시만). 「목록」/「새로 조사」 = 단체예약 목록에 있는지, 「단체」/「개인」 = 단체인지 (따로 판단)
- **같은 날 엑셀을 다시 넣으면 성명 기준으로 맞춤** (2026-11-20, `mergeVisitors`): 예약이 늘거나 취소돼서 새로 받은 엑셀 — **성명이 같으면 이전 줄 그대로**(고친 내용 · 입장문 · 연락 체크 · 고른 것 · 연결 유지, 엑셀 값도 이전 것), **새 엑셀에 없는 성명은 그 줄 삭제**(고친 것도 함께), **새 성명은 새 줄**. 같은 성명이 여러 줄이면 위에서부터 하나씩 짝지음. 넣은 뒤 「새 예약 ○건 추가 · 없어진 예약 ○건 삭제 (이름) · 그대로 ○건」 알림. 단체예약 목록에서 온 줄(엑셀에 없는 단체예약)은 그대로. 예전엔 새 엑셀을 넣으면 표를 통째로 바꿔 고친 것이 사라졌음. 다른 날 엑셀은 지금처럼 날짜 확인 팝업
- **비고 = 엑셀 비고 그대로** (2026-11-19): ④ 표 · 엑셀 · 이미지의 비고는 전산 방문자내역 엑셀의 비고 칸 그대로 (상품 이름 · 단체예약 식사 · 프로그램을 만들어 붙이지 않음 · 글자 수도 자르지 않음). 현장결제건은 단체예약 결제 방법이 현장이거나 비고에 「현장」이 있으면
- **비고에 런치 · 디너 안 씀** (2026-11-20, `MEAL_ONLY`): 엑셀 비고의 「런치2부」 「사담 디너」처럼 식사(예약 상품명)만 적힌 조각은 빼고 도착 시간 · 입장문 · 프로그램 · 메모만 (예: 「12:30 곡신문 / 런치2부 / 개별입장」 → 「12:30 곡신문 / 개별입장」). 일출 · 일몰 · 도슨트 · 세미나는 그대로
- **현장결제(곡신) · 비고의 도착 시각** (2026-11-21, `onsiteLabel` · `noteArrive`): 엑셀 비고 「현장결제필요합니다.(곡신)」 → 비고 「현장결제(곡신)」(곡신문에서 현장결제 · 치허도 같음, 문이 없으면 「현장결제」). 비고의 「11:40 치허문」 · 「10시30분 곡신문」 · 「11:40 도착」을 읽어 그 줄의 도착시간 · 입장문 기본값으로 (단체예약 기록이 있으면 그쪽이 먼저, 그다음 비고, 그다음 여행사 등록). 2026-11-20 여행사 도착시간 수정 때 빠졌던 연락처 칸도 다시 채움
- **이미지로 저장 = 표의 비고 그대로** (2026-11-21): 사진(PNG) 비고는 표 「비고」 칸 그대로 — 직접 고치거나 더한 글 · 새로 쓴 비고도 보이고 줄바꿈도 그대로 (예전엔 자동으로 만든 비고만). 엑셀로 받기는 원래 표의 비고
- **입장문 추천 규칙 고치기** (2026-11-19): ④ 「입장문 추천 규칙 보기 · 고치기」에 지금 규칙이 글로 보이고 [규칙 고치기] 팝업에서 기본 문(치허문 / 곡신문 · 겹치면 다른 문) · 겹친다고 보는 범위(앞뒤 분) · 개인고객 기준 인원 · 대형 단체 이름 · 여행사로 보는 글자를 고침. [저장]하면 공유 기록 한 줄(id `gaterules`, 통화 구분 「입장문규칙」)에 저장되어 모든 사람에게 같게, 마지막으로 고친 사람 표시. 「처음 규칙으로」(저장해야 바뀜). 직접 바꾼 입장문 · 예약 고정은 그대로 (`rules` · `paintRules` · `saveRules`)
- **연락 체크** (2026-11-19): ④ 표 맨 앞(1열) 「연락」 칸에 줄마다 체크 (연락했으면 체크 · 칸이 연한 초록). 제목 옆에 「연락 n/전체」. 이 브라우저에 기억(엑셀을 새로 넣으면 처음부터) · 인쇄 · 엑셀 · 이미지에는 안 들어감
- **④ 표 직접 고치기 · 수정 내용 저장** (2026-11-19): 이름 · 인원 · 도착시간 · 입장문 · 차량 · 연락처 · 비고 모두 표에서 고침. 처음 값(엑셀 · 단체예약)과 다르고 아직 저장하지 않은 칸은 노란 테두리, 버튼에 「수정 내용 저장 (n)」. 누르면 ① 단체예약과 연결된 줄은 그 단체예약에 바로 반영(이름 → 업체명 · 인원 → 관람 인원 · 도착시간 → 입장시각 · 차량 숫자 → 버스 n대 · 연락처 → 첫 연락처 · 입장문 → 비고 칸 「입장문」 · 비고는 수정 기록에만) + 수정 기록 「[다음날 고객 응대 준비] …」 ② 고친 사람의 나의 할일 › 기타 개인 업무에 「전산내용 재반영: 날짜 다음날 고객 응대 수정 n건」 (오늘 마감 · 세부 과업 = 고친 내용 하나씩 · 메모에 전체). 저장한 칸은 다시 저장되지 않음 (`rowChanges` · `saveEdits`)
- **단체예약 반영 다시** (2026-11-19): 저장하는 순간 공유 기록의 최신 예약을 받아 그 위에 고친 칸만 바꿔 넣음(화면이 받아 둔 옛 목록으로 다른 칸을 덮지 않음) · 인원을 고치면 예약 내역 관람 줄도 맞춤 · 단체 화면 수정 기록과 같은 모양(칸마다 전 → 후)으로 남김 · 저장 뒤 다시 받아 정말 들어갔는지 확인, 안 들어갔으면 「저장 못 함: 단체예약에 반영되지 않음 …」. 단체고객 전화응대 화면은 30초마다 받아 올 때 열어 둔 예약이 다른 곳에서 바뀌었으면 새로 불러오고(고치는 중이면 안 고친 칸만 받아 넣음, `liveSync`) → 옛 내용으로 다시 저장해 덮어쓰지 않음
- **수정 내용 저장 = 표 내용 그대로 올림** (2026-11-19 다시, `saveEdits`): 고친 칸만이 아니라 단체예약과 연결된 줄은 표에 적힌 업체명 · 관람 인원 · 입장시각 · 차량 · 연락처 · 입장문을 그대로 단체예약에 올림(같으면 그대로, 빈칸은 지우지 않음). 전산에 등록한 예약이 바뀌면 그 예약의 추후 과업 「전산 예약 수정」을 바로 만들거나 다시 엶(바뀐 것: 「관람 인원 24 → 23」 · 단체 화면에서 열면 전산에 올린 때와 비교해 다시 맞춤, 되돌리면 저절로 완료). 나의 할일 기타 업무 「전산내용 재반영」은 더 만들지 않음
- **단체예약 연결 칸** (2026-11-19): 「자동으로 찾기」 · 「개인으로 (연결 안 함)」을 합쳐 「연결 안 함」 하나 + 그날 단체예약. 처음에는 자동으로 찾아 맞는 단체가 골라져 있고, 못 찾으면 「연결 안 함」
- **팀 공유** (2026-11-19, `sharePush` · `pullShared` · `packState`): 다음날 고객 응대 준비 내용(엑셀 · 고른 줄 · 연결 · 표에서 고친 것 · 연락 체크)을 준비할 날짜마다 공유 기록 한 줄(id `prepYYYYMMDD` · 통화 구분 「응대준비」)에 저장 → 누가 열어도 같은 내용. 고칠 때마다 1.5초 뒤 올리고 30초마다 · 창으로 돌아올 때 남이 고친 것을 받아 옴(고치는 중이면 기다림, 마지막에 저장한 것이 이김). 날짜 줄 오른쪽에 「팀과 공유됨 시각」. 엑셀 줄은 상품 이름을 번호로 줄여 저장(300줄 ≈ 2만 자). 「지우기」는 확인 팝업 → 「지우기」를 한 번 더 눌러야 모두의 화면에서 지움(단체예약에 올린 내용은 그대로)
- **안내 명단 상품** (2026-11-19, `noticeBoxHTML` · `noticeLists`): ③ 응대 표 아래에 그날 엑셀의 상품 이름을 모두 띄우고 체크(체크한 것이 맨 위 · 인원은 체크한 것만) → 체크한 상품을 예약한 고객을 ③ 표 아래 · 이미지 · 엑셀에 「상품: 이름(n명, 전화번호), …」 (해오름은 끝에 「고객 도착 AM 6:00」). 기본은 관람권만(네이버 포함) · 사담 런치 · 디너 · 몽몽마방 사유의 밥상 · 해오름 산책은 끄고 나머지(선셋디너 등)는 켬. 고른 것은 팀 공유(공유 기록 `prepnotice`, 모든 날짜 공통). 예전에 늘 나오던 「해오름 산책」 줄은 없앰(고를 때만)
- **지난 기록 = 달력** (2026-11-19 바꿈): 「지난 기록」 드롭다운은 없앰. 준비할 날짜 달력에서 날짜를 고르면 그날 마지막으로 저장된 기록이 열림(없으면 「이 날짜는 저장된 기록이 없습니다」 · 빈 화면). 준비할 날짜는 늘 내일(오늘 +1) — 다른 날을 고르기 전까지, 켜 둔 채 자정이 지나면 1분 안에 저절로 다음 날 (`dateAuto` · `keepTomorrow`)
- **준비할 날짜를 바꾸면** (2026-11-19, `switchDate`): 하던 날짜 내용은 팀에 저장(이 PC에도 날짜별 사본 `sayuwon_prep_bak_YYYYMMDD`) → 새 날짜는 팀이 준비해 둔 것이 있으면 그것, 없으면 완전히 빈 화면(엑셀부터). 어제 것이 남은 채 열어도 같음 (예전의 「엑셀 날짜가 다릅니다」 팝업 대신)
- **이름 대신 최종 편집 시각** (2026-11-19, `editLab`): 여러 명이 함께 고치므로 날짜 줄 「팀과 공유됨 · 최종 편집 11/19(목) 15:06」, 지난 기록 「11/20(금) · 최종 편집 …」, 받아 올 때 「다른 곳에서 고친 내용을 받아 왔습니다 (최종 편집 …)」 — 이름은 안 씀
