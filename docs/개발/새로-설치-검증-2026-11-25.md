## 3. 문장만으로는 안 되는 것 (사람 · 계정)

1. **Git 과 Claude Code 설치** — 이 PC 에는 이미 있었습니다. 없는 PC 에서의 설치는 확인하지 못했습니다.
2. **GitHub 계정 + 이 저장소의 Collaborator 초대** — 없으면 받기 · 고치기 · 내 PC 에서 보기까지는 되고 올리기(`git push`)가 거절됩니다. 이 PC 는 만든 사람의 계정이라 됐고, **새 사람의 계정으로 올리는 것은 확인하지 못했습니다.**
3. **멤버 등록 + 이름 · 사번을 메모장으로 적기** (`tools\my-login.json`) — 없으면 백업 · 「새 개발 시작」 · 테스트 DB 로그인이 안 됩니다.
4. **열쇠(`TEST_SYNC_KEY`) 받기** — 없으면 「새 개발 시작」의 DB 복사가 안 됩니다. 못 받았으면 새로 만들어 Cloudflare 테스트 서버의 값을 바꿉니다 (`개발-시작하기.md` 6절 · Cloudflare 초대 필요).
5. **Claude Code 에서 받은 `sayuwon-sales` 폴더를 다시 여는 것** — 빈 폴더에서 주소만 준 첫 세션은 괜찮지만, 다시 열지 않으면 다음 세션은 `CLAUDE.md` 를 자동으로 읽지 못합니다. Claude 가 끝에 그렇게 알리게 해 두었습니다.

## 4. 확인하지 못한 것

- **백업을 PC 에 거는 것**(`tools\backup.ps1 -Setup` · 작업 스케줄러 등록)은 이번 새 설치에서는 돌리지 못했습니다 (사람의 허락이 필요한 일이라 자동으로는 막힘). 같은 날 앞서 예전 폴더에서 걸기 → 상태 → 풀기를 한 번 돌려 본 것이 전부입니다. **지금은 어느 PC 에도 백업이 걸려 있지 않습니다.**
- 테스트 DB 로 로그인해서 화면을 쓰는 것 (진짜 이름 · 사번이 필요해 Claude 가 하지 않음 — 사람이 테스트 사이트에서 봅니다).
- Cloudflare 에 서버 코드를 붙여 넣는 흐름 (이번에는 서버 코드가 바뀌지 않음).
- 휴대폰 폭에서의 화면.
- Windows 가 아닌 PC (도구가 PowerShell 이라 Windows 를 전제로 합니다).
