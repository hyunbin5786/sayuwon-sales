# 명령 모음 (Claude 없이 직접 할 때)

PowerShell 에서, 모두 `sayuwon-sales` 폴더 안에서 실행합니다. 평소에는 Claude 에게 말로 시키면 되고([개발-시작하기.md](../../개발-시작하기.md) 7절), 이 표는 직접 해야 할 때 봅니다.

| 하는 일 | 명령 |
|---|---|
| **지금 상태 점검** (백업 · 브랜치 · 서버 · 먼저 할 일) | `powershell -ExecutionPolicy Bypass -File tools\check.ps1` |
| 내 PC 에서 화면 띄우기 → http://localhost:8767/ | `powershell -ExecutionPolicy Bypass -File tools\serve.ps1` (다른 번호: 뒤에 `-Port 8770`) |
| 백업: 걸기 / 지금 한 번 / 상태 / 풀기 | `powershell -ExecutionPolicy Bypass -File tools\backup.ps1 -Setup` / (없이) / `-Status` / `-Unregister` |
| 새 개발 시작 (코드 + DB) | `powershell -ExecutionPolicy Bypass -File tools\test-start.ps1` |
| DB 만 / 코드만 / 세어만 / 열쇠 복사 | 위 명령 뒤에 `-DbOnly` / `-CodeOnly` / `-DryRun` / `-CopyKey` |
| 단체 화면 합치기 (`js/group/` → `js/group.js`) | `powershell -ExecutionPolicy Bypass -File tools\build.ps1` |
| `?v=` 올리기 (CSS · JS 를 고쳤을 때) | `powershell -ExecutionPolicy Bypass -File tools\bump.ps1` |
| 코드 지도(`docs\코드-지도.md`) 다시 만들기 | `powershell -ExecutionPolicy Bypass -File tools\map.ps1` |
| 테스트에 올리기 | `git status --short` 로 바뀐 것을 보고 → `git add 고친-파일…` (모르는 파일은 넣지 않음) → `git commit -m "무엇을 고쳤는지"` → `git push origin test` |
| 푸시 (test → main) | 먼저 `git status -sb` (저장 안 한 수정 · 올리지 않은 커밋이 없어야 함) · `git fetch` · `git log --oneline origin/main..origin/test` 로 무엇이 가는지 확인 → `git checkout main` → `git pull --ff-only` → `git merge test` → `git push origin main` → `git checkout test` |
| 서버 코드를 클립보드에 | `Get-Content cloudflare\worker.js -Raw -Encoding UTF8 \| Set-Clipboard` |

- 화면은 꼭 `http://localhost:…` 로 엽니다 (파일을 더블클릭해 열면 동작하지 않음 · `127.0.0.1` 로도 안 됨).
- 주소 끝에 `?mock=1` 을 붙이면 **가짜 자료**로 엽니다 (로그인 `테스트` / `T001` · 인터넷은 필요). `?mock=0` 으로 끕니다 — 끈 뒤에는 로그아웃하고 내 이름 · 사번으로 다시 로그인합니다. 포트 번호를 바꾸면 처음 여는 주소에 다시 `?mock=1` 을 붙입니다.
- `?mock=1` 없이 `localhost` 로 연 화면은 **테스트 DB**(진짜 자료의 사본)를 씁니다. 오른쪽 아래 이름표로 어느 DB 인지 확인합니다.
- 테스트 환경을 처음 만드는 법 · 서버 동작 `mirror` 는 [45 테스트 환경](45-테스트-환경.md).
