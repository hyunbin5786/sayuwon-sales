# 넘겨받을 때 확인할 것 (앞 담당자와 함께)

만든 사람이 떠나면 **그 사람 계정 · PC 에 묶여 있던 것**이 끊깁니다. 넘겨받는 날 하나씩 확인합니다. (처음 읽는 안내는 [개발-시작하기.md](../../개발-시작하기.md).)

- [ ] **GitHub 저장소 · Cloudflare 계정은 앞 담당자의 개인 계정 그대로 둡니다** (2026-11-25 정함). 그래서 새 담당자가 GitHub Collaborator 로, Cloudflare 계정 멤버로 **초대돼 있어야** 합니다. 앞 담당자와 연락이 끊기면 서버 · DB 에 들어갈 길이 없어지므로, 계정을 옮길지는 나중에 다시 정합니다 (저장소를 옮기면 사이트 주소가 바뀜)
- [ ] **백업을 새 담당자 PC 에 걸었는지** (개발-시작하기 5절 · 「백업 걸어 줘」 → 「백업 확인해줘」). 앞 담당자 PC 의 자동 백업은 2026-11-25 에 풀었습니다 — 새 담당자가 걸 때까지는 아무 PC 에도 걸려 있지 않습니다
- [ ] **열쇠** (`TEST_SYNC_KEY`) 를 받았는지 — 못 받았으면 개발-시작하기 6절대로 새로 만들어 바꿈
- [ ] 관리자 사이트 자동 가져오기 계정(`ADMIN_ID` · `ADMIN_PW` · Cloudflare 배포 서버의 비밀 값)이 누구 것인지 — 그 계정이 없어지면 사담 · 마방 현황 자동 가져오기가 멈춤
- [ ] 예전 구글 시트 · Apps Script · 예전 견적서 사이트(되돌릴 때만 쓰는 사본)를 누가 갖고 있을지
