# 사유원 예약 접수 도우미

전화를 받으면서 메모를 대충 치면 엑셀 메인 시트 형식(D~V열)에 맞춰 예약 칸이 채워지고, 아직 안 물어본 것과 다시 확인할 것을 알려 줍니다. 단체예약 신청란 · 메일 내용을 붙여넣어도 됩니다.

사용: https://hyunbin5786.github.io/sayuwon-sales/

## 쓰는 순서

1. 맨 위 **받는 사람**에 이름을 적습니다 (이 브라우저에 기억)
2. 전화가 오면 왼쪽 **통화 메모**에 들리는 대로 칩니다. 입력을 시작하면 통화 시작 시각이 찍힙니다
   - 줄여 써도 됩니다: `12/4` `다음주 목` `35명` `학생 40명 인솔 2명` `10:30~15` `버스1` `사담1부` `마방 비빔밥` `차방·동행·당두` `이체/카드/현장`
3. 오른쪽 **아직 안 물어본 것**을 보며 질문합니다 (누르면 그 칸으로 이동). **다시 확인할 것**에 날짜·요일 불일치, 대략 인원, 시간 앞뒤가 바뀐 경우가 나옵니다
4. 끊기 전에 **복창 문구**를 읽어 줍니다
5. **Ctrl+S** 저장 → **Alt+N** 새 통화

## 규칙

- 직접 고친 칸은 메모를 더 쳐도 바뀌지 않습니다. 칸에서 Enter = 다음 칸
- **통화 구분**(단체예약 / 일반 문의 / 기타)은 메모를 보고 자동으로 고릅니다 (10명 이상, '단체' '견적' '버스' 등). 틀리면 눌러서 바꿉니다
- 단체예약만 예약 목록에 쌓이고, 일반 문의 · 기타는 한 줄 요약만 **전체 통화 기록**에 남습니다
- **엑셀 행 복사**: 엑셀 메인 시트의 해당 날짜 행 D열(업체) 칸을 선택하고 Ctrl+V 하면 V열(유루 캐빈)까지 들어갑니다

## 공유 저장 (구글 시트)

`index.html`의 `SHARED_URL`에 Apps Script 웹 앱 주소가 있으면 모든 통화 기록이 구글 시트 `calls` 시트에 한 줄씩 저장되어 모두가 같은 목록을 봅니다. 주소가 비어 있으면 각자 브라우저에만 저장됩니다.

- 설치: `group-intake.gs` 맨 위 설명대로 script.google.com 새 프로젝트에 붙여넣고 `PASSCODE`(팀 비밀번호)를 바꾼 뒤 `setup` 실행 → 웹 앱으로 배포 (실행 사용자: 나 / 액세스: 모든 사용자)
- 고객 연락처가 들어가므로 **팀 비밀번호**가 맞아야 읽고 쓸 수 있습니다. 비밀번호는 Apps Script 코드에만 있고 이 저장소에는 없습니다. 사이트에서 처음 한 번 넣으면 그 브라우저에 기억됩니다
- 인터넷이 끊기거나 비밀번호를 넣기 전에 저장한 것은 브라우저에 모아 두었다가 연결되면 올립니다 (맨 위 표시: "연결 안 됨 · n건 대기")
- 창으로 돌아올 때와 1분마다 최신 목록을 다시 불러옵니다
- 지우면 시트에서 줄을 없애지 않고 `삭제` 칸에 일시를 적습니다
- `group-intake.gs`를 고친 뒤에는 **배포 관리 → 편집 → 새 버전**으로 다시 배포합니다 (주소는 그대로)
