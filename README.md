# 사유원 예약 관리 시스템

주소: https://hyunbin5786.github.io/sayuwon-sales/

사유원 예약팀이 전화 응대 · 단체 예약 접수 · 다음날 응대 준비 · 견적서 발급 · 할 일 관리를 한곳에서 하는 웹 시스템입니다. 화면은 GitHub Pages(정적 HTML · CSS · JS), 공유 기록은 구글 시트(Apps Script 웹 앱)에 있습니다.

---

## 1. 폴더 구조

```
index.html            첫 화면: 로그인 · 메뉴 · 품목관리(#catalog) · 멤버관리(#members)
personal.html         1. 개인고객 전화응대
group.html            2. 단체고객 전화응대 (+ 7. 마이페이지 = group.html?my=1)
prep.html             3. 다음날 고객 응대 준비
mypage.html           예전 주소 → group.html?my=1 로 넘김
document/             4. 견적서 / 거래명세서 (+ 5. 품목관리 창 = document/?catalog=1)
  index.html
  css/document.css
  js/document.js      견적서 · 품목 목록(CATALOG_RAW · 굿즈 · 단체 프로그램 · TAX_SPLIT)
  js/datebox.js       날짜 칸
css/
  portal.css  group.css  personal.css  prep.css
  mypop.css           마이페이지 팝업 (첫 화면 · 개인고객 · 다음날 준비 공통)
js/
  portal.js  group.js  personal.js  prep.js
  ime.js              칸별 한글/영어 입력 (단체 · 개인고객 공통)
  mypop.js            마이페이지 팝업 (첫 화면 · 개인고객 · 다음날 준비 공통)
apps-script/
  group-intake.gs     공유 기록 · 멤버 · 관리자 사이트 가져오기 (Apps Script에 붙여 넣는 코드)
```

- HTML에는 화면 틀만, 모양은 `css/`, 동작은 `js/`에 있습니다. 로그인 확인처럼 화면이 그려지기 전에 돌아야 하는 몇 줄만 HTML `<head>` 안에 남겨 두었습니다
- **CSS · JS를 고치면 HTML의 `?v=날짜` 를 바꿔 주세요** (예: `js/group.js?v=20261114` → `?v=20261115`). 그래야 브라우저가 예전 파일을 쓰지 않습니다
- 단체 · 개인고객 화면은 품목 · 가격을 `document/js/document.js` 를 읽어서 가져옵니다 (견적서 코드의 `CATALOG_RAW` 등). 견적서 코드를 옮기거나 이름을 바꾸면 `js/group.js` · `js/personal.js` 의 `QUOTE_DATA` 도 같이 바꿉니다
- 예전 견적서 사이트(https://hyunbin5786.github.io/sayuwon-invoice-quotation/, 저장소 `sayuwon-invoice-quotation`)도 그대로 열리지만, 이 시스템은 `document/` 를 씁니다

## 2. 공통 규칙

- **로그인**: 이름 + 사번. 멤버 목록(공유 시트 `members` 탭)과 맞아야 들어갑니다 (이름 띄어쓰기는 무시). 이미 로그인한 브라우저도 첫 화면을 열 때 다시 확인하고, 멤버에서 빠졌으면 로그아웃. 로그인하지 않고 다른 화면을 열면 첫 화면으로. 멤버 목록은 저장소 코드에 두지 않습니다
- **헤더**: 모든 화면 위쪽 초록 줄이 같습니다. 「사유원 예약 관리 시스템」(누르면 메뉴) › 지금 화면 이름 · 한/A · 👤 로그인한 이름 · 마이페이지 · 그 화면의 버튼
- **날짜 칸**: 칸 안에 `2026-12-05 (토)`. 누르면 달력, 달력을 연 뒤 한 번 더 누르거나 숫자를 치면 직접 입력(`2026-12-05` · `12/5` · `1205` · `12월 5일`, 연도가 없으면 올해 · 지났으면 내년). 새로 만드는 날짜 칸도 이 방식
- **한글 먼저**: 이름 · 업체 · 담당자 · 과업 칸은 들어가면 늘 한글부터 (입력기가 영문이어도 두벌식으로 조합). 영어는 한/영 키 · Shift+Space · 헤더 「한/A」 (`js/ime.js`)
- **연락처**: 빈 칸을 누르면 `010-`, 치는 동안 `010-0000-0000` 모양 (010- 다음 숫자 4개를 치면 바로 `-`)
- **팀 비밀번호**: 공유 기록을 읽고 쓰려면 필요. Apps Script 스크립트 속성 `PASSCODE` 에만 있고 저장소에는 없습니다. 한 번 넣으면 그 브라우저에 기억
- **개인정보**: 고객 이름 · 연락처가 들어간 파일 · 데이터는 저장소에 넣지 않습니다 (공유 시트 · 각자 브라우저에만)

## 4. 개인고객 전화응대 (`personal.html`)

- **헤더**: 👤 이름 옆 **마이페이지**(빨간 `과업 n` = 마감이 오늘이거나 지난 내 과업, 팝업은 **개인** 탭부터) · 오른쪽 「전화문의 응대 매뉴얼 ↗」(노션) · **「통화 기록 전체」**
- **통화 기록** (왼쪽, 제목 줄 오른쪽에 「보고 글자 복사」 · 「저장 (Ctrl+S)」 · 「＋ 새 통화」)
  - **구분**: 예약취소 · 결제링크 · 기타문의 중 하나 (다시 누르면 해제). **＋**로 추가, 칩 안 **×**로 삭제(기본 구분도). 추가 · 삭제는 공유 기록(id `pcats`, 통화 구분 `개인구분`)에 저장되어 모든 사람에게 같게. 삭제한 구분도 이미 저장된 통화에는 그대로 남고 점선 칩으로 보임
  - **보고전달자**: 멤버 이름 칩에서 하나 (나는 빠짐 · 안 골라도 됨)
  - **예약 여부**: 예약함 / 예약 안 함
  - 고객 이름 · 연락처 · 방문 희망일 / 예약일 · 인원 · 문의 내용
- **보고 글자 복사** (카카오톡 보고용)
  ```
  [구분] 담당자 -> 보고전달자      (보고전달자가 없으면 "[구분] 담당자")
  고객 이름 : 홍길동
  연락처 : 010-1234-5678
  방문 희망일/예약일 : 11/27(금)
  인원 : 2명
  문의내용 : …
  ```
- **추후 과업** (오른쪽): 단체 화면과 같은 모양 · 동작. 위에 고정된 「과업 직접 추가」(마감 기본 오늘), ⠿ 끌어서 · ▲▼ 순서, 체크, 마감일, × 삭제, 세부 과제(모두 체크하면 완료), 메모. 저장한 통화면 바로 저장 (메모는 칸을 벗어날 때)
- **통화 기록 전체**: 모든 직원이 받은 개인고객 통화 표 (저장 · 고객(앞에 구분) · 연락처 · 방문일 · 인원 · 문의 · 남은 과업 · 삭제 · 맨 끝 **받은 사람**(초록)). 검색, 줄을 누르면 왼쪽에 열림
  - **삭제**: 사유를 골라야 삭제 (같은 통화를 두 번 저장 · 잘못 입력 · 테스트 · 다른 고객 기록에 잘못 저장 · 단체 예약으로 옮김 · 고객이 기록 삭제를 요청 · 기타(직접 입력)). 사유는 그 기록의 수정 기록에 남은 뒤 삭제. 왼쪽 통화 기록에는 삭제 버튼이 없습니다
  - **「삭제된 통화」**: 삭제 일시 · 삭제한 사람 · 사유 · 고객 · 연락처 · 방문일 · 문의 · 받은 사람 (보기 전용)
- **저장**: 공유 시트 `calls` 에 통화 구분 **개인고객**으로 (이름 → 고객 담당자, 방문일 → 방문일, 문의 → 통화 메모, 받은 사람 = 로그인한 이름). 구분 · 보고전달자 · 예약 여부 · 과업은 수정 기록 칸(JSON), 비고 칸에도 `구분 결제링크 / 보고전달자 김팀장 / 예약 여부 예약함`

## 5. 단체고객 전화응대 (`group.html`)

단체예약 전화를 받으며 예약 칸을 채우고, 물어볼 것 · 가격 · 그날 예약 현황을 바로 봅니다. 저장한 예약은 팀 전체가 구글 시트로 함께 보고, 전산 등록 · 견적서 · 세금계산서 · 결제 확인 같은 뒷일은 추후 과업으로 챙깁니다.

### 5-1. 화면

| 위치 | 내용 |
|---|---|
| 헤더 | 한/A · 👤 로그인한 이름(= 영업 담당) · **마이페이지**(`과업 n` · `메모 n`) · ＋ 새 통화(Alt+N) · 단체상담 입력 · 단체예약 목록 · 품목 관리 · DB 저장 시각 |
| 1열 | **예약 내용** (예약 단계 · 저장 · 견적서 · 거래명세서 · 텍스트 복사, 기본 · 담당자 · 방문 칸, **예약 내역**, 할인 · 합계, 통화 메모) |
| 2열 | 통화 중 확인(물어볼 것) · **예약 현황** · **수정 기록** |
| 3열 | **추후 과업** |

- 헤더는 문제가 있을 때만 연결 상태를 보여 줍니다 (`연결 끊김 · 2건 대기 · 다시 시도 중`). **DB 저장 시각**은 이 브라우저에서 마지막으로 저장된 시각(예약 저장 · 품목 관리 저장 중 최근 것)
- 처음 열면 늘 입력 화면부터 (마이페이지 팝업은 기억하지 않음)

### 5-2. 예약 내용

- **예약 단계**: 예약상담(결제 미정 · 기본) / 예약접수(결제 방식을 고르거나 버튼으로). 예약접수가 되면 전산 예약 과업 등 자동 과업이 생깁니다
- **업체 · 담당자 성함**: 한글부터. **이메일**은 늘 영어. **담당자** 여러 명(＋ 담당자 추가 · ▲로 대표 바꾸기 · ×)
- **방문일 · 관람 인원**(`42+2`, 인원 변경 가능성 체크) · **입장 / 퇴장**(24시간, `1330` → `13:30`, 빈 칸을 누르면 12:00) · **입장문**(치허문 · 곡신문 · 미정) · **차량**(버스 · 승용 · 혼합 · 미정) · **결제**(미정 · 세금계산서 · 결제링크 · 현장 결제, 결제링크면 현장 재결제 체크)
- **미정 체크**: 업체 · 방문일 · 관람 인원 · 입장 칸의 ☐미정, 결제 미정. 미정이 있으면 제목 줄에 **미정 항목 답변일**(기본 = 방문일 전주 목요일, 지났으면 전날). 더 늦추면 사유 팝업
- **입장문은 미정 항목이 아님**: "입장하실 문은 입장 전날 전화드리면서 안내드리겠습니다."
- **확인해 주세요 팝업**: 지난 날짜 · 시각 형식 · 퇴장이 입장보다 빠름 · 답변일 늦음 · 특별 할인 증빙 안내 등 이상한 값이 새로 생기면 바로
- **결제 방식 안내 팝업**: 결제를 고르면 그 방식의 안내 (세금계산서 · 결제링크 · 현장 결제)

### 5-3. 예약 내역 (품목 줄)

- 「＋ 항목 추가」로 넣습니다 (관람이 자동으로 생기지 않음 · 관람권도 직접). 드롭다운 묶음: 관람 · 관람+식사(관람권 · 사담 런치 1부 · 2부 · 디너 · 몽몽마방 사유의 밥상 등 패키지 · 새벽 해오름 산책) · 몽몽마방 · 개별 프로그램 · 시간 프로그램 · 굿즈
- 줄 구성
  1. **[품목(이름만) · 금액 · 인원(수량) · 담당 · ×]** — 금액 칸은 **할인까지 뺀 실제 결제 금액**을 `과세(신라) 1,800,000원` / `비과세(사유원) 1,125,000원`으로 (그 줄 전체, 마우스를 올리면 정상가 − 할인). 과세 · 비과세 나누기: 품목 관리의 과세 · 비과세 비율 → 관람+식사는 그날 관람권 가격만큼 비과세 → 관람권은 모두 비과세 → 그 밖은 모두 과세
  2. **할인 줄** (할인 대상 품목만): 「할인 없음 · 사전예약 5% · 단체예약 10%」 버튼 · **할인액 과세(신라) · 비과세(사유원) 칸**(버튼의 %로 계산한 할인을 과세 · 비과세 비율로 나눈 값, 칸에서 바로 고치면 「직접 고침」 · ↺로 되돌리기 · 할인 버튼을 바꾸면 고친 값은 지워짐 · 시트 비고 칸 `항목 할인액 sadam1=200000:100000`) · 금액. 고친 할인액은 합계 · 사유원/신라 · 세금계산서 문구에 반영 (견적서로는 % 할인만 넘어감)
  3. **비고** (할인이 없는 품목은 바로 비고, 금액은 그 줄 끝 · 그 옆 **「할인 넣기」**를 누르면 할인 대상이 아닌 품목(해오름 산책 · 프로그램 등)도 과세 · 비과세 할인액 칸이 열림, 예: 해오름 9명 중 8명 사담 식사로 관람료 400,000원 공제 → 비과세(사유원) 400,000). 몽몽마방은 시간 · 결제(사무실 / 마방), 도슨트는 시간대 · 코스
- **할인 자동**: 할인 대상(관람 · 사담 런치 등)은 관람 인원으로 자동 선택 — 20명 이하 사전예약 5%, 20명 초과 단체예약 10%. 버튼으로 바꾸면 「직접 바꿈」, 금액 · 합계 · 사유원/신라 · 견적서에 바로 반영 (비고 칸에 `항목 할인 sadam1=pre`). **특별 할인 인원**(간송 15% · 국가유공자 30% · 군위 주민 50% · 대구대교구 무료)은 단체 할인과 비교해 큰 쪽. **기타 할인**은 **과세(신라) 금액 · 비과세(사유원) 금액**을 직접 넣고 사유 (과세는 신라 몫, 비과세는 사유원 몫에서 빠짐 · 예전 기록의 금액 + 대상은 그쪽 칸으로 읽음 · 전산 기타할인은 과세로)
- **담당**: 개별 · 시간 프로그램 · 굿즈는 필수(기본 = 영업 담당). 굿즈 담당은 늘 영업 담당
- **합계 · 사유원 / 신라**: 품목 관리의 과세 · 비과세 비율로 나눔 (없으면 관람 = 사유원, 그 밖 = 신라)
- **전산 내역 붙여넣기**: 사유원 전산의 상품 정보를 통째로 붙이면 줄의 금액 칸이 **전산 금액**(과세(신라) · 비과세(사유원), 품목의 과세 · 비과세 비율로 나눔)으로 바뀌고, 그 아래 줄에는 **할인만**(과세 · 비과세 할인액 · 전산 할인 사유) 나오며 **할인액은 여기서도 고칠 수 있고**(할인이 없는 상품은 「할인 넣기」, 고치면 전산 합계 · 사유원/신라도 그 금액으로, ↺ = 전산 할인으로),, 예약 내용과 다르면 어느 쪽에 맞출지 팝업 (전산이 맞음 / 예약 내용이 맞음 → 전산 수정 과업). 예약 내역에 없는 전산 상품은 「전산에만 있는 상품」(「＋ 항목으로 추가」). 결제 정보(과세 · 면세)도 붙이면 그 금액이 사유원 / 신라. **전산 예약 · 전산 예약 수정 과업은 전산 내역을 붙여 넣어야 완료**
- **몽몽마방 메뉴**: 품목 관리에서 식사로 보이는 기본 메뉴(사유의 밥상(단체) · 몽몽마방 런치 · 몽몽마방 단품)와 예약상품명이 `몽몽마방 ○○`로 시작하는 식사 품목. 고르지 않으면 과업 「몽몽마방 메뉴 선택」
- **새벽 해오름 산책**: 금 120,000원 · 토/일 · 공휴일 139,000원(관람료 포함, 할인 대상 아님)
- 공휴일은 코드(`HOLIDAYS`)에 2026 ~ 2027년. 임시공휴일 · 2028년은 추가해야 합니다

### 5-4. 예약 현황 (3열)

- 버튼 4개 **몽몽마방 · 대관 · 도슨트 · 프로그램** (방문일이 있으면 그날 건수). 누르면 **예약 목록** 창이 그 탭으로 (지난 예약도 보기 · 방문일과 같은 날 줄은 초록 · 줄을 누르면 그 예약). 사담은 예약 전산에서 확인
- **대관 · 도슨트 · 프로그램**: **예약접수**된 **다른 단체** 예약(지금 열어 둔 예약은 빼고)에서 자동(「단체예약」 표시 · 줄을 누르면 그 예약) + 아래 **「직접 추가」**로 넣은 예약(줄마다 「수정」 · ×). 직접 넣은 것은 공유 기록 한 줄(id `bookdb`, 통화 구분 `예약현황추가`), 180일 지난 것은 정리. 「엑셀 표를 한 번에 넣기」: 일자 · 업체 · 인원 · 동행 도슨트 시간 · PPT 도슨트 시간 · 대관 시간 · … · 담당 · 비고 표를 붙여 넣으면 시간이 있는 칸마다 한 건 (대관 장소는 넣은 뒤 「수정」에서)
  - 대관: 일자 · 업체 · 인원 · 장소(몽몽차방 = 차방 대관 · 당두봉갈) · 담당자 이름 · 비고사항
  - 도슨트: 일자 · 업체 · 인원 · 시간 · 종류(동행 = 동행 도슨트 · PPT = 세미나 도슨트) · 담당자 이름 · 비고사항
  - 프로그램: 일자 · 업체 · 인원 · 프로그램 항목 · 담당자 이름 · 비고사항
- **몽몽마방** 탭: 아래 **「직접 추가」**(날짜 · 시간 · 예약자 · 업체 · 인원 · 메뉴)로 한 건씩, 줄마다 「수정」 · × (엑셀 붙여넣기는 없앰 · 처음 한 번만 썼음). 공유 기록 한 줄(id `mabangdb`, 통화 구분 `몽몽마방예약`). 90일 지난 것은 정리

### 5-5. 버튼

- **저장**(Ctrl+S): 마지막으로 고친 뒤 30초면 자동 저장. 저장 버튼 옆 ● = 저장 안 한 변경
- **견적서 · 거래명세서**: 앞 체크를 켜면 과업(생성 · 전송 · NAS 업로드). 누르면 저장 뒤 `document/` 가 새 탭으로 열려 자동으로 채워지고, 출력한 파일은 드라이브에 저장되어 과업에 링크
- **텍스트 복사**: 카카오톡 보고용 `[단체예약 보고] …`

### 5-6. 추후 과업 · 수정 기록

- 예약상담에는 자동 과업이 없고(사전답사 전산 예약만), 직접 추가한 과업은 씁니다
- **전산 내역 대조 (총 금액 · 할인)** (예약접수면 「전산 예약」과 함께 늘 생김): 전산에 예약을 넣은 뒤 전산 내역을 붙여 넣으면, 예약 내용으로 계산한 **할인 합계**(할인 버튼 % + 기타 할인)와 **총 금액**을 전산 내역과 비교해 둘 다 같으면 **저절로 완료**, 다르면 열린 채로 어디가 다른지(예약 ○원 / 전산 ○원) 보여 줌. 전산 내역을 다시 붙여 넣거나 예약을 고치면 다시 비교. 직접 체크는 안 됨. 「전산 내역 합계」 아래에도 같은 ✓ / ✗ 표시
- 자동 과업: 사전답사 전산 예약 · 미정 항목 확인 연락(답변일) · 현장 결제 인원 확인 연락(전주 목요일) · 몽몽마방 식당에 시간 확인 · 몽몽마방 메뉴 선택 · 프로그램 · 굿즈 담당 입력 · 담당자에게 일정 전달(방문 전날) · 굿즈 준비(방문 전날) · 전산 예약 · 전산 예약 수정 · 견적서 발급 · 거래명세서 발급 · 세금계산서 발행(사업자등록증 올리기) · 결제 확인(결제링크 다음날)
- 마감일 · 끌어서 순서 · 세부 과제 · 메모 · 끝난 과업은 한 줄(자세히 ▾) · 기한 지남 빨강. 전산 비고 · 세금계산서 · 현장 결제 문구는 자동으로 만들고 직접 고칠 수 있음. **전산 비고**에는 지금 적용된 **사유원 · 신라 금액**(할인 · 기타 할인 · 줄에서 고친 할인액 · 전산 내역 반영, 현장결제면 「현장결제 필요」, 그 밖은 결제 방식)과 **기타할인**(사유원 · 신라 금액 · 사유) · **줄에서 고친 할인액**이 들어감
- **수정 기록** (2열 예약 현황 아래, **늘 접혀 있고** 「▸ 수정 기록 n건」을 누르면 펼침): 바뀐 칸마다 값의 흐름(`관람 인원 20 → 22 → 25`) · 시각 · 고친 사람. 한 번 여는 동안의 자동 저장은 한 줄에 모임. 줄마다 **이 버전으로 돌아가기**(미리보기)
- 저장 안 한 채로 다른 예약을 열면 「저장하고 나가기 / 저장하지 않고 나가기」. 새로고침해도 보던 예약 · 저장 안 한 입력 · 펼친 묶음 · 열어 둔 목록 · 스크롤 그대로

### 5-7. 남이 담당인 예약 (잠금 · 메모)

- 영업 담당이 다른 사람인 예약을 열면 🔒 표시와 함께 칸 · 예약 내역 · 과업 · 단계 · 저장 · 견적서 버튼이 모두 막힙니다 (텍스트 복사 · 예약 현황은 됨). 목록의 수정 · 삭제도 담당자만. 영업 담당이 비어 있는 예약은 잠기지 않음
- 바꿀 내용은 위쪽 **「메모 남기기」** → 그 예약 기록(수정 기록 칸의 `memos`)에 쌓임
- 담당자 화면에 **「메모를 확인하세요」** 팝업 (확인 · 열기 · 나중에), 마이페이지 버튼 옆 `메모 n`. 내 예약을 열면 위쪽에 메모 목록. 담당자가 저장해도 그사이 남긴 메모는 지워지지 않음

### 5-8. 단체예약 목록 (헤더 버튼)

- 탭: 전체 · 예약상담 · **예약접수**(기본) · 전산 미등록 · 지난 예약. 검색(업체 · 담당자 · 전화번호 · 영업 담당, 탭과 상관없이 전체에서). 정렬: 방문일 순 · 접수 순
- 열: 방문일 · 단계 · 업체 · 담당자(전화) · 인원 · 입퇴장 · 식사 · 견적서 · 거래명세서 · **영업 담당**(초록) · 접수 · 수정 · 삭제
- **수정**: 단계 · 전산 등록 · 견적서 · 거래명세서 상태를 사유와 함께 고침. **삭제**: 사유를 골라야. 둘 다 수정 기록에 남음
- **삭제된 예약**: 삭제한 예약을 보기 전용 표로 (삭제 일시 · 삭제한 사람 · 사유 · 방문일 · 업체 · 담당자 · 인원 · 영업 담당)
- **엑셀로 내려받기**: `사유원_단체예약현황_YYYYMMDD.xlsx` · **관리자 사이트에서 지금 가져오기**

### 5-9. 단체상담 입력 (헤더 버튼)

admin > 예약상담관리의 상담 내역을 통째로 붙여 넣고 「칸에 채우기」. 상품으로 식사 · 프로그램을 채우고(런치1부 → 사담 1부 · 도슨트 → 동행 도슨트 1시간 등), 출발지 · 모르는 항목 · 답사 요청 정보는 통화 메모에. 사전 답사가 있으면 과업 「사전답사 전산 예약」

## 6. 다음날 고객 응대 준비 (`prep.html`)

견적서처럼 순서대로 진행합니다. 엑셀 내용은 **이 브라우저 안에서만** 읽고 어디에도 올리지 않습니다 (고친 내용은 이 브라우저에 기억).

1. **엑셀 파일 넣기**: 전산 → 방문자내역에서 받은 파일(예: `2026-11-15_방문자내역.xls`, HTML 표 모양)을 끌어다 놓기. 열: 구분 · 방문일 · 성명 · 연락처 · 예약일시 · 프로그램유형 · 예약인원(어른 · 학생) · … · 결제수단 · 금액 · 입장정보 · 비고. 한 줄 = 한 예약이고 상품이 여러 개면 칸 안에서 줄바꿈 (상품마다 인원, 모두 더해 예약 인원)
2. **10인 이상 목록**: 인원이 기준(기본 10명) 이상인 예약 + 그날 단체예약에 있는 예약. 체크로 빼기. 「단체예약 연결」에서 직접 고르기(자동으로 찾기 · 개인으로)
3. **단체예약 정보 넣기**: 연락처가 같거나 이름 · 업체명이 맞으면 자동 연결 → 업체명 · 도착 시간(입장) · 차량 · 연락처 · 비고(엑셀 상품 · 사담/마방 식사 · 프로그램 · 현장결제 · 통화 메모 · 전산 비고)를 가져옴. 단체예약에는 있는데 엑셀에 없으면 「전산에 없음」
4. **입장문 추천 · 응대 표**: 예전 엑셀표 모양 (날짜(요일) · 방문 인원+@ / 인원 / 도착시간 / 입장문 / 차량 / 연락처 / 비고, 아래 단체 합계 · 버스 대수 · 개인고객 인원 · 현장결제건 · 해오름 산책). 도착 시간 · 입장문 · 차량 · 연락처 · 비고는 표에서 바로 고침. **표 복사**(구글 시트 · 엑셀에 붙여넣기) · **엑셀로 내려받기** · **인쇄**
   - 입장문 추천 규칙 (줄마다 이유 표시, 「입장문 다시 추천」)
     - 기본 **치허문**. 여행사(여행 · 투어 · 관광)와 해밀 · 아너드 · 군위시티투어는 치허문
     - 그 대형 단체가 오는 시간(앞뒤 30분)과 겹치는 **다른 개별 단체**는 **곡신문**
     - 시간이 안 겹치면 단체는 모두 치허문
     - **15명 이상 개인고객은 곡신문**. 15명 미만 개인은 단체와 겹치면 곡신문, 아니면 치허문
     - 도착 시간을 모르면 치허문 (시간을 넣으면 다시 추천)

## 8. 품목관리 (`#catalog`)

예약 상품 · 가격 · **과세(신라) · 비과세(사유원)**(정상가를 나눠 적는 품목만: 비과세 = 입장료 = 사유원 몫, 과세 = 신라철강 몫) · 할인 대상 · 구분. 구분 순서 · 버튼: **전체 › 관람 › 관람+식사 › 식사 › 단체(시간) › 단체(개별) › 굿즈** (몽몽마방 메뉴 구분은 없애고 식사로). 고치고 2초 뒤 자동 저장(공유 Apps Script). 단체 · 개인고객 화면의 가격 · 몽몽마방 메뉴 · 프로그램 칸이 이 목록을 따라갑니다.

## 9. 멤버관리 (`#members`)

로그인할 수 있는 직원(이름 · 사번). 한 명씩 추가 · 「여러 명 한꺼번에 추가」(한 줄에 "이름 사번") · 빼기. 팀 비밀번호 필요. 멤버가 한 명도 없을 때는 누구나 로그인되고 안내가 뜹니다.

## 10. 마이페이지 (`group.html?my=1`)

- 탭 **전체 · 개인 · 단체** (고른 탭 기억. 개인고객 화면에서 열면 개인, 단체고객 화면에서 열면 단체부터 · 주소 `&tab=personal`)
  - 전체: 1열 개인 추후 과업 · 2열 단체 추후 과업
  - 개인: 추후 과업(개인) · 내가 받은 개인고객 통화(최근 50)
  - 단체: **방문 예정(예약접수만)** · 단체 추후 과업. 「지난 방문도 보기」
- **오늘 마감**인 과업은 노란색(그 과업 줄 + 카드), 마감이 지난 과업은 빨간색
- 줄을 누르면 단체는 단체 화면에서 그 예약(`group.html?open=예약ID`), 개인은 개인고객 화면에서 그 통화

## 11. 공유 기록 (구글 시트 · Apps Script)

`apps-script/group-intake.gs` 를 웹 앱으로 배포한 주소(`SHARED_URL`)로 모든 화면이 같은 시트를 씁니다.

- 시트 `calls`: 한 줄 = 한 기록. **통화 구분** 칸으로 나눔 — 예약상담 · 예약접수(예전: 단체예약 · 상담 · 가예약 · 공식예약) = 단체, `개인고객` = 개인 통화, `몽몽마방예약`(id `mabangdb`) = 몽몽마방 예약 목록, `개인구분`(id `pcats`) = 개인고객 구분 목록, `예약현황추가`(id `bookdb`) = 직접 넣은 대관 · 도슨트 · 프로그램
- 시트 `members`: 이름 · 사번 · 추가 일시 · 추가한 사람 · 삭제
- 열: ID · 저장 일시 · 통화 시작 · 받은 사람 · 통화 구분 · 요약 · 방문일 · 업체 · 담당 · 결제 · 차량 · 입퇴장 · 관람 · 사담 1부 · 사담 2부 · 사담 디너 · 마방 런치 · 마방 디너 · 차방 · 동행 · 당두 · 요가/명상 · 가가 바우처 · 티하우스 명상 · 가야금 · 유루 캐빈 · 고객 담당자 · 연락처 · 이메일 · 입장 · 퇴장 · 식사 여부 · 마방 메뉴 · 비고 · 통화 메모 · 수정 일시 · 삭제 · 수정 기록
- 열을 늘리지 않으려고 함께 적는 칸
  - 비고 칸(` / `로 구분): 미정 체크 · 답변일 · 늦춘 사유 · 전산 등록 · 입장문 · 인원 변경 · 현장 재결제 · 서류 요청 · 몽몽마방 시간/결제 · 굿즈 · 기타 할인 · 항목 비고 · **항목 할인** · 관람 품목 · 특별 할인 · 추가 프로그램 · 프로그램 담당 / 시간대 / 코스 (개인 통화는 구분 · 보고전달자 · 예약 여부)
  - 수정 기록 칸(JSON): `{h: 수정 기록, tasks: 추후 과업, erp: 전산 내역, memos: 남긴 메모}` (개인 통화는 `{h, tasks, cat, reportTo, reserved}`)
  - 담당자가 여러 명이면 담당자 · 연락처 · 이메일 칸에 같은 순서로 ` / `
- 지우면 줄을 없애지 않고 `삭제` 칸에 일시 → 「삭제된 예약」 · 「삭제된 통화」로 봄
- 끊긴 사이 저장한 것은 브라우저에 모았다가 15초마다 다시 올림. 1분마다 · 창으로 돌아올 때 최신 목록

**Apps Script 동작**: `list` · `put` · `del` · `deleted`(삭제된 기록) · `upload`(사업자등록증 · 견적서 파일 → 드라이브) · `syncAdmin` · `login`(비밀번호 없이 이름 + 사번 확인만) · `members` · `memberAdd` · `memberDel`

### 설치 · 다시 배포

1. script.google.com 프로젝트에 `apps-script/group-intake.gs` 를 붙여넣고 저장
2. 프로젝트 설정 → 스크립트 속성: `PASSCODE`(팀 비밀번호), `ADMIN_ID` · `ADMIN_PW`(관리자 사이트 계정, 조회 전용 권장)
3. `setup` 실행 → 시트 만들기 / `setupUpload` 실행 → 드라이브 권한(폴더 `사유원 단체예약 서류`, 팀원 계정에 공유)
4. `testAdmin` → 로그 확인 / `setupAdminSync` → 15분마다 자동
5. 배포 → 웹 앱(실행: 나 / 액세스: 모든 사용자). 코드를 고치면 **배포 관리 → 편집 → 새 버전**(주소 그대로)
