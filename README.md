# 사유원 예약 접수 도우미

단체예약 전화를 받으면서 예약 칸을 채우고, 물어볼 것 · 다시 확인할 것 · 복창 문구를 보여 줍니다.

사용: https://hyunbin5786.github.io/sayuwon-sales/

## 화면

- 왼쪽부터 **예약 내용 · 통화 중 확인 · 통화 메모**
- 맨 위 **단체예약 목록** 버튼을 누르면 목록이 창으로 뜹니다 (숫자 = 전체 건수, 빨간 표시 = 전화 필요 건수). 줄을 누르면 그 예약을 불러오고 창이 닫힙니다. Esc · 닫기 · 바깥을 누르면 닫힘
- 맨 위 **단체상담 입력** 버튼: admin > 예약관리 > 예약상담관리에 있는 상담 내역(신청번호 · 상품 · 기관명 · 소속 · 성명 · 연락처 · 이메일 · 일자 · 인원 · 시간 · 교통수단 · 주차대수 · 출발지)을 통째로 붙여넣고 **칸에 채우기**를 누르면 칸이 채워집니다. 탭 · 띄어쓰기 · 콜론(:) 어느 형식이든 되고, 모르는 항목은 통화 메모에 `항목: 값`으로 남습니다. 기본은 새 통화로 시작 (체크를 풀면 지금 내용에 덧붙임)
- **상담 정보 (선택)**: 상담 신청번호 · 상품 · 출발지. 필수 아님. 시트에는 비고 칸에 `상담 신청번호 604 / 상품 관람 / 출발지 서울`처럼 함께 적습니다

## 쓰는 순서

1. **영업 담당** 칸에 이름을 한 번 적으면 이 컴퓨터에 기억됩니다
2. 전화를 받으며 **예약 내용** 칸을 채웁니다. 입력을 시작하면 통화 시작 시각이 찍힙니다
3. 가운데 **물어볼 것**: 필수 항목이 빨간 칸으로 나오고, 받은 항목은 초록색으로 바뀝니다 (마우스를 올리면 물어볼 문장). **다시 확인할 것**에 지난 날짜, 입퇴장 시간 뒤바뀜, 관리자 사이트 기준 사담 · 마방 자리 부족 · 마감이 나옵니다
4. **사담 식사 · 몽몽마방 식사 · 프로그램**은 처음에 접혀 있습니다. 한 줄에 있는 버튼 3개를 누르면 아래에 펼쳐지고, 다시 누르면 접힙니다. 값이 들어간 묶음은 버튼이 초록색이 되고 내용이 요약됩니다 (예: `사담 식사 1부 35명`). 펼친 묶음 아래에 **방문일의 예약 현황**(이 도우미에 저장된 예약 + 관리자 사이트)이 나오고, 칸에 커서를 두면 그 칸을 이미 쓴 업체가 보입니다
5. 오른쪽 **통화 메모**에는 칸에 없는 특이사항(휠체어, 요청사항 등)을 적습니다. 예약 칸을 자동으로 채우지는 않습니다
6. 끊기 전에 **복창 문구**를 읽어 줍니다
7. **Ctrl+S** 저장 → **Alt+N** 새 통화

## 입력 방식

- **단체명 · 담당자 성함 · 영업 담당**: 칸에 들어가면 항상 한글부터. 컴퓨터 입력기가 영문 상태여도 두벌식 한글로 들어갑니다. 영어는 **한/영 키**, Shift+Space, 또는 위쪽 **한** 버튼(→ **A**)
- **이메일**: 항상 영어. 입력기가 한글이어도 누른 자판 글자로 들어갑니다 (붙여넣은 한글도 자판 글자로 바뀜)
- **연락처**: 빈 칸을 누르면 `010-`이 들어가고, 숫자를 치면 `-`가 자동으로 들어갑니다 (`010-1234-5678`, `053-987-6543`, `02-1234-5678`). 내선 번호면 `010-`을 지우고 치면 됩니다 (`1234`)
- **입장**은 필수, **퇴장**은 선택
- **결제**: 세금계산서 · 결제링크 · 현장 결제 · 미정 중에서 고릅니다. **미정**이면 **결제 연락 예정일**(언제 알려주기로 했는지) 칸이 나오고 필수가 됩니다
- **미정 항목 입력 기한**: 인원 · 식사 등 아직 정해지지 않은 내용을 언제까지 알려주기로 했는지 날짜 (선택). 복창 문구에도 들어갑니다
- 시트에는 열을 늘리지 않고 결제 칸에 `미정 (연락 2026-11-20)`, 비고 칸에 `미정 항목 입력 기한 2026-11-25`로 함께 적습니다 (Apps Script 다시 배포 필요 없음)
- **관람 인원**: 숫자와 `+`만 (`42+2`). **차량**: 차종(버스 · 승용 · 혼합)을 고르고 대수는 숫자만
- **영업 담당**: 한 번 적으면 이 컴퓨터에 기억되어 계속 그 사람이 담당. 자동 등록된 예약을 열어도 이 컴퓨터의 영업 담당으로 채워집니다

## 규칙

- 단체예약만 다룹니다
- 칸에서 Enter = 다음 칸
- 담당자는 **+ 담당자 추가**로 여러 명(성함 · 연락처 · 이메일) 넣을 수 있고, × 로 뺍니다. 첫 번째 담당자의 세 칸이 필수입니다

## 공유 저장 (구글 시트)

`index.html`의 `SHARED_URL`에 Apps Script 웹 앱 주소가 있으면 모든 예약이 구글 시트 `calls` 시트에 한 줄씩 저장되어 모두가 같은 목록을 봅니다. 주소가 비어 있으면 각자 브라우저에만 저장됩니다.

- 설치: `group-intake.gs` 맨 위 설명대로 script.google.com 새 프로젝트에 붙여넣고 `PASSCODE`(팀 비밀번호)를 바꾼 뒤 `setup` 실행 → 웹 앱으로 배포 (실행 사용자: 나 / 액세스: 모든 사용자)
- 고객 연락처가 들어가므로 **팀 비밀번호**가 맞아야 읽고 쓸 수 있습니다. 비밀번호는 Apps Script 코드에만 있고 이 저장소에는 없습니다. 사이트에서 처음 한 번 넣으면 그 브라우저에 기억됩니다
- 인터넷이 끊기거나 비밀번호를 넣기 전에 저장한 것은 브라우저에 모아 두었다가 연결되면 올립니다 (맨 위 표시: "연결 안 됨 · n건 대기")
- 창으로 돌아올 때와 1분마다 최신 목록을 다시 불러옵니다
- 지우면 시트에서 줄을 없애지 않고 `삭제` 칸에 일시를 적습니다
- `group-intake.gs`를 고친 뒤에는 **배포 관리 → 편집 → 새 버전**으로 다시 배포합니다 (주소는 그대로)

시트 열: ID · 저장 일시 · 통화 시작 · 받은 사람 · 통화 구분 · 요약 · 방문일 · (엑셀 D~V열과 같은 순서: 업체 ~ 유루 캐빈) · 고객 담당자 · 연락처 · 이메일 · 입장 · 퇴장 · 식사 여부 · 마방 메뉴 · 비고 · 통화 메모 · 수정 일시 · 삭제

- 담당자가 여러 명이면 고객 담당자 · 연락처 · 이메일 칸에 같은 순서로 ` / ` 로 이어 적습니다 (예: `김민정 / 박준호`, `010-1234-5678 / 010-9999-8888`)
- 통화 구분은 항상 `단체예약`, 비고 칸은 더 이상 쓰지 않습니다 (예전 기록 호환용으로 열은 남겨 둠)

## 관리자 사이트(admin.sayuwon.com) 자동 가져오기

Apps Script가 15분마다 관리자 사이트에 로그인해서 두 가지를 가져옵니다.

- **사담 · 마방 현황**: 사담 런치1부 · 런치2부 · 디너, 몽몽마방 사유의 밥상의 날짜별 정원 · 현재 인원 · 팀 수 (이번 달부터 4개월). 사담 · 마방 칸 아래 현황에 `관리자 사이트 · 사담 런치1부 49/57명 · 10/19팀 · 남은 8명`처럼 나오고, 마감이면 빨간색
- **15명 이상 예약**: 오늘부터 180일 안의 예약 완료 건 중 15명 이상이면 목록에 **전화 필요**로 들어갑니다 (예약자 · 연락처 · 방문일 · 인원 · 상품 · 관리자 예약번호가 미리 채워짐). 열어서 전화로 받은 내용을 채우고 저장하면 표시가 없어집니다. 같은 예약은 관리자 예약번호로 한 번만 들어갑니다

목록 위 **관리자 사이트에서 지금 가져오기**로 바로 가져올 수도 있습니다.

설정 (Apps Script)
1. 새 `group-intake.gs`를 붙여넣고 저장
2. 프로젝트 설정(톱니바퀴) → 스크립트 속성: `PASSCODE`(지금 쓰는 팀 비밀번호), `ADMIN_ID`, `ADMIN_PW`(관리자 사이트 계정, 조회 전용 계정 권장)
3. `testAdmin` 실행 → 실행 로그에 "로그인 성공 · 사담 n일 · 15명 이상 n건"
4. `setupAdminSync` 실행 → 15분마다 자동 (트리거)
5. 배포 → 배포 관리 → 편집 → 새 버전 → 배포
