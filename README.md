# 사유원 예약 관리 시스템

주소: https://hyunbin5786.github.io/sayuwon-sales/

> **날짜 입력은 모든 화면에서 같은 방식**: 칸 안에 `2026-12-05 (토)`처럼 날짜와 요일, 칸을 누르면 바로 달력, 달력을 연 뒤 한 번 더 누르거나 숫자를 치면 직접 입력(2026-12-05 · 12/5 · 1205, 연도를 안 쓰면 올해 · 이미 지났으면 내년). 단체 방문일 · 개인 방문 희망일 / 예약일 · 개인 과업 마감일 · 견적서 이용일 · 발행일. 앞으로 새로 만드는 날짜 칸도 이 방식
## 0. 첫 화면 · 로그인 · 메뉴 (`index.html`)

- 처음 열면 **이름 + 사번**으로 로그인합니다. 이 브라우저에 기억되고(`sy_user`), 단체 화면의 **영업 담당**과 견적서의 **담당**에 이 이름이 들어갑니다. 로그아웃하면 지워집니다
- **멤버만 로그인**: 이름 + 사번이 멤버 목록(공유 구글 시트 `members` 탭)과 맞아야 들어갑니다. 틀리면 "이름과 사번이 맞지 않습니다. 다시 확인해 주세요." (이름의 띄어쓰기는 무시). 이미 로그인한 브라우저도 첫 화면을 열 때 다시 확인해, 멤버에서 빠졌으면 로그아웃. 멤버 목록은 GitHub 코드에 두지 않습니다
- **처음 설정**: 멤버가 한 명도 없을 때는 아무 이름 · 사번으로나 들어가지고 메뉴 위에 안내가 뜹니다 → 멤버관리에서 본인 포함 직원을 추가하면 그때부터 확인. Apps Script가 예전 버전이면 확인하지 못하고 들어가지며 '새 버전으로 배포' 안내가 뜹니다
- 공유 기록은 지금처럼 팀 비밀번호(Apps Script 스크립트 속성 PASSCODE)로 보호됩니다
- 로그인 뒤 메뉴 6개
  1. **개인고객 전화응대** — `personal.html` (아래 「개인고객 전화응대」)
  2. **단체고객 전화응대** — `group.html` (아래 설명하는 단체 예약 접수 및 관리 도우미)
  3. **견적서 / 거래명세서 발급** — 이 사이트 안 `document/` (https://hyunbin5786.github.io/sayuwon-sales/document/). 견적서  3. **견적서 / 거래명세서 발급** — https://hyunbin5786.github.io/sayuwon-invoice-quotation/거래명세서 발행기 코드를 그대로 옮긴 것이고, 예전 주소 https://hyunbin5786.github.io/sayuwon-invoice-quotation/ 도 그대로 열림. 단체 화면의 견적서 · 거래명세서 버튼 · 가격표 · 품목관리도 이 `document/`를 씀
  4. **품목관리** — 주소 `…/sayuwon-sales/#catalog`. 메뉴에서 열면 **한 페이지**(테두리 · × 없이 헤더 아래 꽉 차게, 위쪽 「사유원 예약 관리 시스템」을 누르면 저장이 끝난 뒤 메뉴로). 단체고객 전화응대 · 견적서/거래명세서의 「품목 관리」 버튼도 모두 이 `#catalog`를 **팝업**(가로 1200px, 두 화면 같은 크기)으로 띄움
  5. **멤버관리** — 로그인할 수 있는 직원 목록. 팀 비밀번호 필요(단체 화면과 같음). 한 명씩 추가(이름 · 사번) 또는 「여러 명 한꺼번에 추가」에 한 줄에 한 명 "이름 사번"(띄어쓰기 · 탭 · 쉼표) 붙여넣기, 이미 있는 사번은 건너뜀. 「빼기」로 제외(시트에는 삭제 일시 · 한 사람이 남음). 본인 줄에는 (나)
  6. **마이페이지 · 나의 할 일** — `mypage.html` (한 페이지). 위쪽 탭 **전체 · 개인 · 단체**. 전체 = 1열 **개인 추후 과업** · 2열 **단체 추후 과업** (2열) / 개인 = 내 개인고객 통화의 추후 과업 · 내가 받은 개인고객 통화(최근 50) / 단체 = 방문 예정(**예약접수만**, 예약상담은 빼고) · 단체 추후 과업 (2열). 다른 사람이 수정한 내 예약 칸은 없앰. 고른 탭은 기억. 메뉴 6번으로 열면 **한 페이지**(팝업 모양 없음, 「☰ 메뉴」로 돌아감). 첫 화면 위쪽 · 개인고객 · 단체고객 화면의 「마이페이지」 버튼은 같은 내용을 **팝업**(가로 최대 1200px, × · 바깥 · Esc로 닫기)으로 띄움. 단체 줄을 누르면 단체 화면에서 그 예약(`group.html?open=예약ID`), 개인 줄을 누르면 개인고객 화면에서 그 통화가 열림
- **모든 화면의 위쪽 초록 헤더가 같습니다**: 「**사유원 예약 관리 시스템**」(누르면 메뉴로) › 지금 화면 이름 · 그 화면의 버튼 · 👤 로그인한 이름. 따로 있던 「☰ 메뉴」 · 「← 메뉴」 버튼은 없앴습니다 (품목관리 페이지에서 누르면 남은 변경을 저장한 뒤 메뉴로). 견적서 / 거래명세서 화면도 같은 헤더 · 배경으로 바꾸고 「한 · 발급 내역 · 품목 관리」 버튼을 헤더로 옮김. 로그인하지 않고 단체 화면이나 견적서 사이트를 열면 첫 화면으로 보냅니다 (두 사이트가 같은 주소 hyunbin5786.github.io 라 로그인을 함께 씀)

## 개인고객 전화응대 (`personal.html`)

- **위쪽 헤더**: 「전화문의 응대 매뉴얼 ↗」(노션, 새 창) · **「통화 기록 전체」**(모든 직원이 받은 개인고객 통화를 최근 순 표로: 저장 · 고객 · 연락처 · 방문 희망일 / 예약일 · 인원 · 문의 내용 · 남은 과업 · **삭제** · 맨 끝 **받은 사람**(단체예약 목록의 영업 담당처럼 초록 띠), 검색, 줄을 누르면 왼쪽에 열림. **삭제는 사유를 꼭 적어야** 하고 사유는 그 기록의 수정 기록에 남은 뒤 삭제 · 아래 삭제 버튼도 같음) · 마이페이지
- **「저장 (Ctrl+S)」 · 「＋ 새 통화」**는 「통화 기록」 제목 줄 오른쪽 위
- **왼쪽 · 통화 기록**: 고객 이름 · 연락처(빈 칸을 누르면 `010-` 부터, 하이픈 자동) · **방문 희망일 / 예약일** · 인원 · 문의 내용
- **2열 · 추후 과업**(통화마다, 오른쪽) — **단체 화면과 같은 모양 · 동작**: 위쪽에 고정된 「과업 직접 추가」(마감 기본 오늘), 과업마다 ⠿ 끌어서 순서 · 체크 · ▲▼ · 마감일(방문일 방식 날짜 칸) · × 삭제 · **세부 과제**(추가 · 체크 · 빼기, 모두 체크하면 완료) · **메모**. 순서는 마감일이 빠른 순(같으면 최근 추가가 위, 직접 옮긴 순서는 유지), 기한 지남은 빨강, 끝난 과업은 회색으로 맨 아래 한 줄(자세히 ▾). 이미 저장한 통화면 체크 · 순서 · 마감일 · 세부 과제는 바로, 메모는 칸을 벗어나면 저장
- **저장**(Ctrl+S): 단체 화면과 같은 공유 기록(구글 시트 `calls`)에 통화 구분 **개인고객**으로 한 줄 (이름 → 고객 담당자, 방문 희망일 / 예약일 → 방문일, 문의 내용 → 통화 메모, 추후 과업 → 수정 기록 칸). 받은 사람 = 로그인한 이름. 단체예약 목록 · 마이페이지에는 나오지 않음. 같은 팀 비밀번호
- **＋ 새 통화** · **삭제**(시트에는 삭제 표시)

# 단체고객 전화응대 (`group.html`, 예전 이름: 사유원 단체 예약 접수 및 관리 도우미)

단체예약 전화를 받으면서 예약 칸을 채우고, 물어볼 것 · 고객님께 읽어 드릴 확인 문장 · 가격을 바로 보여 줍니다. 저장한 예약은 팀 전체가 구글 시트로 함께 보고, 전산 등록 · 견적서 · 세금계산서 · 결제 확인 같은 뒷일은 추후 과업으로 챙깁니다.

사용: 첫 화면에서 로그인 → **단체고객 전화응대** (https://hyunbin5786.github.io/sayuwon-sales/group.html)

---

## 1. 화면 구성

| 위치 | 내용 |
|---|---|
| 맨 위 초록 헤더 | 한/A(입력 언어) · **👤 로그인한 이름**(= 영업 담당, 첫 화면에서 로그인 · 여기서 바꾸지 않음) · **마이페이지**(이름 바로 옆) · **＋ 새 통화** · **단체상담 입력** · **단체예약 목록** · **품목 관리** |
| 1열 **예약 내용** | 제목 줄 오른쪽에 **미정 항목 답변일**, 회색 칸에 **예약 단계**(예약상담 · 예약접수)와 버튼 4개(**저장 · 견적서 · 거래명세서 · 텍스트 복사**), 아래로 기본 · 담당자 · 방문 칸, 식사 · 프로그램 버튼 4개, 맨 아래 **통화 메모** |
| 2열 **통화 중 확인** | 물어볼 것 · **가격표** |
| 3열 | **추후 과업**(체크리스트) · **수정 기록** |

헤더는 문제가 있을 때만 상태를 보여 줍니다 (예: `연결 끊김 · 2건 대기 · 다시 시도 중`). 정상일 때는 아무것도 표시하지 않습니다. 맨 오른쪽에는 **DB 저장 시각**(`DB 저장 11/13(금) 14:10`, 이 브라우저에서 구글 시트(Apps Script) DB에 마지막으로 저장된 시각: **예약 저장**(고치고 30초 뒤 자동)과 **품목 관리 저장**(고치고 2초 뒤 자동) 중 최근 것)이 늘 보이고, 올릴 것이 남아 있으면 `· 저장 대기 1건`이 붙습니다. 아직 저장한 적이 없으면 마지막으로 목록을 받아 온 시각(`DB 동기화 …`). 마우스를 올리면 저장 · 받아 온 시각을 둘 다 보여 줍니다

## 2. 쓰는 순서

1. 헤더 **영업 담당**에 이름을 한 번 적습니다. 이 컴퓨터에 기억되고, 새 예약의 담당 · 수정 기록 · 마이페이지가 이 이름으로 정해집니다
2. 전화를 받으며 **예약 내용** 칸을 채웁니다. 입력을 시작한 시각이 시트의 통화 시작 칸에 저장됩니다 (화면에 통화 시간은 보이지 않음)
3. 가운데 **물어볼 것**을 보며 빠진 것을 묻습니다. 받은 항목은 초록, 미정으로 체크한 항목은 노랑, 아직 안 받은 항목은 빨강입니다 (마우스를 올리면 물어볼 문장)
4. 끊기 전에 받은 내용을 고객님께 확인합니다 (자동 확인 멘트 칸은 없앴습니다)
5. **저장**(Ctrl+S) → **＋ 새 통화**(Alt+N)

## 3. 예약 내용 칸

### 예약 단계
- **예약상담**: 결제가 **미정**(기본)인 동안. 일부만 적어도 저장됩니다
- **예약접수**: 결제 방식(세금계산서 · 결제링크 · 현장 결제)을 고름. 결제가 미정이어도 예약을 받았으면 버튼으로 예약접수를 고릅니다. 사유원 전산에 등록해야 하며 추후 과업에 **전산 예약**이 생깁니다
- 결제 칸을 보고 자동으로 고르고(점선 테두리), 버튼으로 직접 바꿀 수 있습니다. 예전에 상담으로 저장한 예약은 예약상담, 가예약 · 공식예약은 예약접수로 보입니다

### 기본 · 담당자 · 방문
- **업체 · 담당자 성함 · 영업 담당**: 칸에 들어가면 항상 한글부터 (입력기가 영문이어도 두벌식 한글). 영어는 한/영 키, Shift+Space, 또는 헤더의 **한** 버튼
- **이메일**: 항상 영어 (입력기가 한글이어도 누른 자판 글자로)
- **연락처**: 빈 칸을 누르면 `010-`, 숫자를 치면 `-` 자동 (`010-1234-5678`, `053-987-6543`, `02-1234-5678`). 내선이면 `010-`을 지우고 입력
- **담당자**: **+ 담당자 추가**로 여러 명, × 로 빼기. 첫 담당자의 성함 · 연락처 · 이메일이 필수. 두 번째 담당자부터 **▲**를 누르면 바로 위 담당자와 자리를 바꿉니다 (맨 위 = 주로 연락하는 대표 담당자: 견적서 수신 · 목록 · 연락처에 쓰임). 담당자가 여러 명이어도 성함 · 연락처 · 이메일 칸의 열이 줄마다 똑같이 맞습니다 (첫 줄에도 ▲ · × 자리만큼 비워 둠)
- **방문일**: 칸을 누르면 **달력**이 먼저 열립니다. 달력이 열린 뒤 칸을 **한 번 더 누르면** 글자로 직접 고칠 수 있습니다 (숫자를 치기 시작해도 바로 직접 입력). `2026-12-05` · `2026.12.5` · `20261205` · `12/5` · `1205` · `12월 5일` 모두 되고, 연도가 없으면 올해(지났으면 내년). 칸에는 `2026-12-05 (토)`처럼 요일까지 보입니다
- **날짜 표시**: 화면 · 문구의 날짜는 모두 끝에 **(요일)**이 붙습니다 (예: `12월 3일 (목)`, `12/5(토)`, 수정 기록 `11/12(목) 09:35`). 미정 항목 답변일 · 과업 마감 달력 칸도 옆에 (요일)이 보이고, 두 칸은 같은 모양입니다. 추후 과업 마감일 · 미정 항목 답변일 칸도 방문일처럼 **칸 안에** `2026-11-14 (금)`으로 보이고, 누르면 달력이 열리며 날짜를 고르는 즉시 요일도 바뀝니다
- **관람 인원**: 숫자와 `+`만 (`42+2`). 옆에 **인원 변경 가능성 있음** 체크
- **입장**(필수) · **퇴장**(선택)은 **24시간 표시 시각**입니다. 숫자만 치면 `:`가 자동으로 들어가고(1330 → 13:30), 칸을 나가면 `09:30` 형식으로 맞춥니다. 입장 칸이 비어 있을 때 누르면 기본 **12:00**이 들어갑니다(선택된 상태라 바로 고쳐 쓰기). 시각이 아니면 확인해 주세요 팝업으로 알림
- **입장문**: 치허문 · 곡신문 · 미정 ("선택" 항목은 없고 기본은 **미정**. 입장문을 안 고른 예전 기록도 미정으로 불러옴)

### 가격표
- **선택한 항목**: **방문일과 관람 인원**이 둘 다 있어야 나옵니다. 하나만 넣으면 가격표에 "관람 인원을 입력해 주세요" / "방문일을 입력해 주세요"가 노란 글씨로 나옵니다. 고른 식사 · 프로그램으로 품목 · 수량 · 단가 · 할인 · 금액 · **예상 합계**. 견적서 발급과 같은 계산입니다
- **관람권**: 방문일이 토 · 일 · 공휴일이면 **주말/공휴일**, 아니면 **평일**. 입장 시각이 **13:00 이후면 13~18시 관람권**, 그 전이거나 모르면 9~18시 관람권
- **공휴일**: 2026 ~ 2027년 공휴일 · 대체공휴일 · 선거일을 코드(`HOLIDAYS`)에 넣어 두었습니다. 임시공휴일이 생기거나 2028년이 되면 추가해야 합니다
- **할인**: 관람 인원 20명 미만 **사전예약 5%**, 20명 초과 **단체예약 10%** (20명은 5%). **관람 · 사담 런치(1부 · 2부)에만** 적용 (가격표 위에 "22명 → 단체예약 10%" 같은 문구는 따로 띄우지 않고, 선택한 항목 표의 할인 칸에만 보입니다)
- **특별 할인 인원**: 간송미술관 제휴 15% · 국가유공자 30% · 군위 주민 50% · 대구대교구 신부 · 수녀 · 신학생 무료. 단체 할인과 비교해 **큰 쪽 하나만** 적용. 비고 칸에 `특별 할인 간송 3, 군위 주민 2`로 저장. 네 칸이 한 줄에 있고 숫자만 들어갑니다 (한글 · 영문은 지워짐)
- **기타 할인**: 특별 할인 아래 칸에 금액(원) · 어느 쪽에서 뺄지(신라 기본 / 사유원) · 사유를 적으면 가격표에 `기타 할인 (사유) -금액` 줄이 생기고 합계 · 사유원 / 신라 금액에서 빠집니다. 시트 비고 칸에 `기타할인 금액 …` 등으로 저장 (견적서로 넘기지는 않음)
- **사유원 / 신라 나누기**: 가격표 · 전산 내역 합계 아래에 `└ 사유원 (비과세 · 입장료)` · `└ 신라 (과세)`. 품목 관리의 **과세 · 비과세** 칸(1인 금액, 예: 관람+사담 런치1부 = 과세 80,000 · 비과세 50,000, 새벽 해오름 산책 평일 = 70,000 · 50,000 · 주말 = 70,000 · 69,000)을 그대로 읽어 품목마다 그 비율로 나눕니다(할인도 같은 비율, 전산 할인 괄호 금액이 있으면 그 금액이 신라 몫). 과세 · 비과세가 없는 품목만 예전 방식(관람 = 사유원, 그 밖 = 신라). 전산 결제 정보(면세 · 과세)를 함께 붙여넣으면 그 금액이 우선. 세금계산서 문구도 같은 금액
- **전산 내역 붙여넣기** (가격표 아래 버튼, 또는 단체상담 입력에 붙여넣어도 됨): 사유원 전산 예약의 상품 정보(`방문일자(순번)` · 상품정보 · 예약인원 · 상품금액 · 할인금액 · 금액)를 통째로 붙여넣으면 상품마다 표로 보여 주고, 전산 합계 · 사유원 / 신라 금액과 **가격표 예상 합계와의 차이**를 알려 줍니다. 예약과 함께 저장되고 **지우기**로 뺄 수 있습니다
  - **예약 내용과 비교합니다**: 붙여넣으면 식사 · 몽몽마방 · 프로그램 · 굿즈 · 방문일 · 관람 인원을 예약 내용과 비교합니다. 같으면 그대로 적용, 예약 칸이 비어 있으면 전산 내역대로 채우고, **다르면 팝업**(항목 · 예약 내용 · 전산 내역 표)으로 어느 쪽에 맞출지 묻습니다 → **전산이 맞음 → 예약 내용 고치기**(예약 칸을 전산 내역대로) · **예약 내용이 맞음 → 전산 고치기**(예약 칸 그대로, 추후 과업 `전산 예약을 예약 내용대로 수정`이 다른 점을 메모로 달고 생김) · **취소**(적용 안 함)
  - **전산 예약 · 전산 예약 수정 완료 = 전산 내역 붙여넣기**: 과업을 체크하면 붙여넣기 창이 먼저 뜨고, 붙여넣어 위 비교를 마쳐야 완료됩니다 (창을 닫거나 취소하면 완료 안 됨, 마이페이지에서도 「완료」 버튼 없이 「열기」만)
  - 아래쪽 **결제 정보**(결제 금액 · 과세금액 · 면세금액(입장료) · 결제 상태 · 결제수단)도 함께 붙여넣으면 사유원 = 면세금액, 신라 = 과세금액으로 보여 주고 결제 줄을 더합니다. 결제 정보의 상품금액이 마지막 상품 금액을 덮지 않습니다
  - **전산 내역이 있으면 가격표 = 전산 내역**: 예약 칸으로 계산하던 예상 금액(선택한 항목) · 특별 할인 · 기타 할인 칸은 숨기고, 전산 내역 표(상품 · 인원 · 상품금액 · 할인 · 금액 · 전산 합계 · 사유원/신라)만 보입니다. 세금계산서 문구의 사유원 · 신라 금액도 전산 기준. 버튼은 「전산 내역 다시 붙여넣기」로 바뀌고, **지우기**를 누르면 예약 칸으로 계산한 가격표로 돌아갑니다
- **전체 가격표 보기**: 관람 · 관람+식사 · 식사 · 단체 프로그램의 평일 · 주말 가격
- 가격과 품목은 **견적서&거래명세서 사이트**에서 그때그때 읽어 옵니다 (그 사이트의 기본 품목, 품목 관리에서 바꾼 가격 · 숨김 · 추가 품목 반영). 불러오지 못하면 마지막으로 받은 가격
- **품목 관리** (헤더의 버튼, 몽몽마방 메뉴 옆 `메뉴 · 가격 수정`): 견적서&거래명세서 사이트의 품목 관리 창을 이 도우미 안에 그대로 띄웁니다. 같은 공유 품목 목록이라 어느 쪽에서 고쳐도 둘 다 바뀝니다. **저장**하거나 닫으면 가격표 · 몽몽마방 메뉴를 다시 불러옵니다

- **예약상담에는 자동으로 생기는 과업이 없습니다** (사전답사 전산 예약만 예외). 대신 **직접 추가한 과업**은 예약상담에서도 그대로 쓸 수 있고 마이페이지 · 알림 팝업에도 나옵니다. 예약접수가 되면 (결제를 정하거나 단계를 바꾸면) 그때 자동 과업이 생깁니다
- **마감일**: 과업이 생기면 **그날**이 마감으로 들어가고, 과업 제목 오른쪽 날짜 칸에서 각자 바꿀 수 있습니다. 미정 항목 확인 연락은 **답변일**, 현장 결제 인원 확인 연락은 **방문일 전주 목요일**(지났으면 전날), 결제 확인은 **다음날**이 기본 (답변일 · 방문일이 바뀌면 직접 바꾸기 전까지 따라감)

- **순서**: **마감일이 빠른 순**이고, 마감일이 같으면 **가장 최근에 추가된 과업이 위**입니다. 직접 옮긴 과업은 그 순서를 그대로 두고, 그 뒤 새로 생긴 과업은 마감일에 맞는 자리(같은 마감일이면 맨 위)에 끼워 넣습니다. 안 끝난 과업은 제목 왼쪽 **⠿**를 잡고 끌어서 놓거나(화면 위 · 아래 끝으로 끌면 저절로 스크롤) 오른쪽 **▲▼**로 바꿀 수 있고, 바꾼 순서는 그대로 유지 · 저장됩니다 (수정 기록에 "과업 순서 바꿈"). 끝난 과업은 맨 아래

### 수정 기록
- **고친 것은 빠짐없이 기록**: 바뀐 칸마다 거쳐 간 값을 모두 남깁니다 (예: `관람 인원 20 → 22 → 25`). 시각 · 고친 사람(헤더의 영업 담당)과 함께, 최근 것부터
- **자동 저장**: 마지막으로 고친 뒤 **30초**가 지나면 저장합니다 (다른 창으로 넘어가면 바로). 업체나 방문일이 있어야 저장되고, 미정 항목 답변일을 늦춘 사유가 필요하면 저장 버튼을 누를 때까지 기다립니다
  - 한 번 열어 고치는 동안의 자동 저장은 수정 기록 **한 줄에 모입니다** (노란 `자동 저장 중 · 저장 버튼을 누르면 확정` 표시). 기록이 자동 저장마다 쌓이지 않습니다
  - **저장** 버튼을 누르면 그 줄이 확정되고, 그 뒤 고친 것은 새 줄로 시작합니다. 저장 버튼 옆 노란 점(●) = 아직 저장하지 않은 변경 있음
  - 과업 체크 · 메모 · 복사는 바로 자동 저장되고, 같은 줄에 모입니다
- **저장하지 않고 나가기**: 저장하지 않은 변경이 있는데 **＋ 새 통화** · 목록 · 마이페이지 · 알림에서 다른 예약을 열면 `저장하지 않은 내용이 있습니다` 팝업 (바뀐 항목 목록 · **저장하고 나가기** / **저장하지 않고 나가기** / 취소). 창을 닫거나 새로 고치면 브라우저가 묻습니다
- **새로고침해도 보던 화면 그대로**: 열어 둔 예약 · 저장하지 않은 입력(메모 · 과업 포함) · 펼친 식사 · 프로그램 묶음 · 열어 둔 단체예약 목록 · 스크롤 위치를 이 브라우저에 기억했다가, 새로고침하거나 창을 다시 열면 그대로 보여 줍니다. 저장하지 않은 입력을 되살리면 "저장하지 않았던 입력을 되살렸습니다" 알림 (저장은 자동 저장 · 저장 버튼으로). 마이페이지 팝업은 기억하지 않아 단체 화면은 늘 입력 화면부터 열립니다 (메뉴 6 마이페이지 페이지도 단체 화면에 영향 없음)
- **이 버전으로 돌아가기**: 수정 기록의 각 줄(지금 버전 제외)에 버튼이 있습니다. 누르면 **미리보기**(항목 · 지금 · 돌아갈 버전)가 뜨고, **이 버전으로 돌아가기** / **돌아가지 않기** 중 고릅니다
  - 돌아가면 그 내용으로 저장되고 수정 기록에 `[되돌리기] 11. 12. 오전 09:35 버전으로 · …`가 남아, 다시 원래대로 돌아올 수도 있습니다
  - 과업 체크 · 메모 · 올린 파일은 되돌리지 않습니다. 이 방식을 쓰기 전(값의 흐름이 없는 예전 기록)보다 앞 버전으로는 돌아갈 수 없습니다
- **담당이 아닌 사람이 남의 예약을 고치면** **저장** 버튼을 누를 때(자동 저장 때는 안 뜸) 그동안 고친 내용으로 **담당자에게 보고해 주세요** 팝업이 뜹니다. 바뀐 내용이 담긴 보고 문구(`[단체예약 수정 보고] …`)를 **복사**해 카카오톡으로 보내면 됩니다. 그 수정은 담당자의 마이페이지에도 표시됩니다

- 목록 창은 화면 폭을 넓게 씁니다(최대 1680px). 맨 오른쪽 **수정(초록) · 삭제(빨강)** 버튼은 크게, 표를 옆으로 밀어도 오른쪽 끝에 늘 보입니다

  - 기본 사유: 잘못 눌러 발행으로 표시됨 · 다른 경로로 이미 발행함 · 고객이 서류 요청을 취소함 · 전산 등록 상태가 실제와 다름 · 예약 단계가 실제와 다름 · 기타
- **삭제**: 사유를 목록에서 고르고(기타는 직접 입력) 삭제. 사유는 수정 기록에 남고, 시트 줄은 지우지 않고 삭제 표시만
- **엑셀로 내려받기**: 지금 탭 · 정렬 그대로 `사유원_단체예약현황_YYYYMMDD.xlsx`
- **관리자 사이트에서 지금 가져오기**: 아래 자동 가져오기를 바로 실행

## 8. 마이페이지 (메뉴 6 · 단체 · 개인 통합 페이지)

**로그인한 사람**이 영업 담당인 단체 예약과, 로그인한 사람이 받은 **개인고객 통화**의 추후 과업을 한눈에 봅니다. 첫 화면 위쪽 · 개인고객 화면 위쪽 「마이페이지」로도 열림(`group.html#my`). 2열 **추후 과업**에 「단체」 · 「개인」 표시로 함께, 마감이 이른 것부터 (개인 줄을 누르면 개인고객 화면에서 그 통화가 열림). 버튼의 숫자도 단체 + 개인 합계. 버튼의 빨간 표시: `과업 n`(마감이 오늘이거나 지난 추후 과업)

2열로 나란히 보여 줍니다 (좁은 화면에서는 위아래로). 열마다 따로 스크롤됩니다. 아래는 **단체** 탭 (전체 탭은 1열 개인 추후 과업 · 2열 단체 추후 과업).

| 1열 | 2열 |
|---|---|
| **방문 예정** (**예약접수만**, 예약상담은 빼고 · 방문일 순 카드: 방문일 · 단계 · 업체 · 인원 · 담당자(전화) · 미정 항목과 답변일 · 견적서/거래명세서 · 남은 과업 수). **지난 방문도 보기**로 전체 | **추후 과업**: 해결 안 된 과업을 **단체(예약)별로** 묶어, 마감이 이른 단체부터. 과업마다 마감일과 남은 날 (지남 = 빨강, 오늘 = 주황). 방문 뒤 30일이 지난 예약은 뺌 |

- 카드를 누르면 그 예약을 불러옵니다

## 10. 단체상담 입력

admin > 예약관리 > 예약상담관리의 상담 내역(신청번호 · 상품 · 기관명 · 소속 · 성명 · 연락처 · 이메일 · 일자 · 인원 · 시간 · 교통수단 · 주차대수 · 출발지)을 통째로 붙여넣고 **칸에 채우기**. 탭 · 띄어쓰기 · 콜론 어느 형식이든 되고, 출발지와 모르는 항목은 통화 메모에 남습니다. 기본은 새 통화로 시작 (체크를 풀면 지금 내용에 덧붙임)
- **상품**으로 식사 · 프로그램을 채웁니다 (인원 단위는 관람 인원, 시간 단위는 1시간): 런치1부 → 사담 1부, 런치2부 → 사담 2부, 디너 → 사담 디너, 몽몽마방 · 사유의 밥상 → 몽몽마방(사유의 밥상), 도슨트 → 동행 도슨트 1시간, 세미나 · 차방 · 당두봉갈 → 각 1시간, 요가 · 사운드워킹 · 사유의 향 · 해오름 산책 → 관람 인원. 채운 묶음은 펼쳐지고, 원래 상품명은 통화 메모에 `상품: …`으로 남습니다
- **답사 요청 정보** 아래 줄(목적 · 일자 · 인원 · 시간 등)은 예약 칸을 덮지 않고 통화 메모에 `[답사] 일자: 2026.11.17(화)`처럼 남습니다. 같은 항목이 두 번 나오면 처음 것을 씁니다
- 사전 답사가 있으면 추후 과업에 **사전답사 전산 예약**이 생기고, 그 과업 메모에 답사 정보(목적 · 일자 · 인원 · 시간)가 들어갑니다. 예약상담이어도 이 과업은 생깁니다. 답사 정보는 시트 비고 칸에 `사전 답사 …`로 저장

## 11. 공유 저장 (구글 시트 · Apps Script)

`group.html`의 `SHARED_URL`(Apps Script 웹 앱 주소)로 모든 예약이 구글 시트 `calls` 시트에 한 줄씩 저장되어 모두가 같은 목록을 봅니다.

- **팀 비밀번호**가 맞아야 읽고 쓸 수 있습니다. 비밀번호는 Apps Script **스크립트 속성 `PASSCODE`**에만 있고 이 저장소에는 없습니다. 처음 한 번 넣으면 그 브라우저에 기억됩니다
- 인터넷이 끊긴 사이 저장한 것은 브라우저에 모아 두었다가 15초마다 다시 올립니다
- 창으로 돌아올 때와 1분마다 최신 목록을 다시 불러옵니다
- 시트에 열을 늘리지 않으려고 일부 값은 기존 칸에 함께 적습니다
  - 결제 칸: `미정 (연락 2026-11-20)`
  - 비고 칸(` / `로 구분): 미정 체크 · 미정 항목 답변일 · 입력 기한 늦춘 사유 · 전산 등록 · 입장문 · 인원 변경 · 현장 재결제 · 견적서/거래명세서 요청 · 특별 할인 · 추가 프로그램(세미나 도슨트 · 새 품목)
  - 수정 기록 칸: `{h: 수정 기록, tasks: 추후 과업}` (JSON)
  - 담당자가 여러 명이면 고객 담당자 · 연락처 · 이메일 칸에 같은 순서로 ` / `
  - 통화 구분 칸: 예약상담 · 예약접수 (예전 기록은 단체예약 · 상담 · 가예약 · 공식예약)

## 12. 관리자 사이트(admin.sayuwon.com) 자동 가져오기

Apps Script가 15분마다 관리자 사이트에 로그인해 (조회만) 두 가지를 가져옵니다.

- **사담 · 마방 현황**: 사담 런치1부 · 런치2부 · 디너, 몽몽마방 사유의 밥상의 날짜별 정원 · 현재 인원 · 팀 수 (이번 달부터 4개월). 식사 칸 아래 현황에 `관리자 사이트 · 사담 런치1부 49/57명 · 10/19팀 · 남은 8명`처럼 나오고, 마감이면 빨간색
- **15명 이상 예약**: 오늘부터 180일 안의 예약 완료 건 중 15명 이상이면 목록에 **전화 필요**로 들어갑니다 (예약자 · 연락처 · 방문일 · 인원 · 상품 · 관리자 예약번호를 미리 채움, 단계는 예약접수 · 전산 등록됨). 열어서 전화로 받은 내용을 채우고 저장하면 표시가 없어집니다. 같은 예약은 관리자 예약번호로 한 번만
