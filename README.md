# 사유원 단체 예약 접수 및 관리 도우미

단체예약 전화를 받으면서 예약 칸을 채우고, 물어볼 것 · 다시 확인할 것 · 확인 문구를 보여 줍니다.

사용: https://hyunbin5786.github.io/sayuwon-sales/

## 화면

- 왼쪽부터 **예약 내용 · 통화 중 확인 · 통화 메모**
- 맨 위 **단체예약 목록** 버튼을 누르면 목록이 창으로 뜹니다 (숫자 = 전체 건수, 빨간 표시 = 전화 필요 건수). 줄을 누르면 그 예약을 불러오고 창이 닫힙니다. Esc · 닫기 · 바깥을 누르면 닫힘
- 맨 위 **단체상담 입력** 버튼: admin > 예약관리 > 예약상담관리에 있는 상담 내역(신청번호 · 상품 · 기관명 · 소속 · 성명 · 연락처 · 이메일 · 일자 · 인원 · 시간 · 교통수단 · 주차대수 · 출발지)을 통째로 붙여넣고 **칸에 채우기**를 누르면 칸이 채워집니다. 탭 · 띄어쓰기 · 콜론(:) 어느 형식이든 되고, 출발지와 모르는 항목은 통화 메모에 `출발지: 서울`처럼 남고, 신청번호 · 상품은 쓰지 않습니다. 기본은 새 통화로 시작 (체크를 풀면 지금 내용에 덧붙임)
- **가격표** (통화 중 확인 아래)
  - **선택한 항목**: 방문일 · 관람 인원과 예약 칸에서 고른 사담 · 마방 · 도슨트 · 요가 · 음료쿠폰으로 품목 · 수량 · 단가 · 할인 · 금액과 **예상 합계**를 보여 줍니다. 견적서 발급과 같은 계산이라 견적서 합계와 같습니다. 견적서 품목에 없는 것(티하우스 명상 등)은 합계에서 빠졌다고 알려 줍니다
  - **전체 가격표 보기** 버튼: 관람 · 관람+식사 · 식사 · 단체 프로그램(1인 / 회당)의 평일 · 주말 가격. 쉐프 특선 코스 · 음료쿠폰(몽몽차방) · 네이버 상품 · 굿즈는 빼고 보여 줌
  - **자동 업데이트**: 가격과 품목은 견적서&거래명세서 사이트에서 그때그때 읽어 옵니다. 그 사이트 코드의 기본 품목 목록이 바뀌거나 **품목 관리**에서 가격을 바꾸거나 품목을 숨기 · 추가하면 여기에도 반영됩니다 (열 때마다, 그리고 10분이 지나 창으로 돌아올 때). 불러오지 못하면 마지막으로 받은 가격으로 표시
  - 공휴일은 날짜로 알 수 없어 주말 가격을 직접 안내
- **할인** (가격표 위): 관람 인원 20명 미만은 **사전예약 5%**, 20명 초과는 **단체예약 10%** (20명은 5%로 계산). **관람 · 사담 런치(1부 · 2부)에만** 적용하고 다른 상품은 할인 없음. 특별 할인 인원(간송미술관 제휴 15% · 국가유공자 30% · 군위 주민 50% · 대구대교구 신부 · 수녀 · 신학생 무료)을 넣으면 그 인원은 단체 할인과 비교해 **큰 쪽 하나만** 적용해 합계를 계산합니다. 특별 할인이 있으면 다시 확인할 것 · 확인 문구에 필요한 증빙(간송 방문 티켓 방문일 기준 6개월 이내, 국가유공자 증서, 주민등록증 · 등본, 소속 증명서 · 신분증)이 나옵니다. 시트에는 비고 칸에 `특별 할인 간송 3, 군위 주민 2`처럼 저장
- **견적서 발급** (예약 내용 아래 버튼): 견적서&거래명세서 사이트를 새 탭으로 열고 자동으로 채웁니다. 수신 = 업체, 수신 담당자 = 첫 담당자, 발신 = 영업 담당, 이용일 · 인원, 품목 = 관람(사담 · 마방 패키지 인원을 뺀 나머지) · 사담 런치1부/2부/디너 · 몽몽마방 사유의 밥상(메뉴가 밥상이거나 비었을 때, 아니면 몽몽마방 단품) · 해설사 도슨트(고른 장소 수만큼 회) · 요가 · 음료쿠폰(가가빈빈), 할인 = 사전예약 5% / 단체예약 10%와 특별 할인 인원. 티하우스 명상 · 가야금 · 유루 캐빈 · 몽몽마방 디너는 견적서 품목이 없어 직접 추가. 고객 정보가 주소에 남지 않도록 두 사이트가 같이 쓰는 브라우저 저장소로 넘깁니다(5분 안, 한 번만)
- **예약 단계** (예약 내용 맨 위): **상담**(결제 미정 전, 일부만 적어도 저장) · **가예약**(결제 **미정** → 사유원 전산에 등록해야 함) · **공식예약**(결제 방식 확정). 결제 칸을 보고 자동으로 고르고(점선), 버튼으로 직접 바꿀 수 있습니다. 가예약 · 공식예약이면 **전산 등록 완료** 체크가 나오고, 체크 전에는 다시 확인할 것에 안내가 뜹니다. 저장 버튼도 `가예약으로 저장`처럼 바뀝니다. 시트에는 `통화 구분` 칸에 단계, 비고 칸에 `전산 등록 2026-11-10`이 저장됩니다. 목록 창에서 전체 · 상담 · 가예약 · 공식예약 · **전산 미등록**으로 걸러 볼 수 있습니다 (관리자 사이트에서 자동으로 온 예약은 전산 등록된 것으로 봄)

## 쓰는 순서

1. 맨 위 초록 헤더의 **영업 담당** 칸에 이름을 한 번 적으면 이 컴퓨터에 기억됩니다 (늘 보이니 내 이름이 맞는지 확인)
2. 전화를 받으며 **예약 내용** 칸을 채웁니다. 입력을 시작하면 통화 시작 시각이 찍힙니다
3. 가운데 **물어볼 것**: 필수 항목이 빨간 칸으로 나오고, 받은 항목은 초록색으로 바뀝니다 (마우스를 올리면 물어볼 문장). **다시 확인할 것**에 지난 날짜, 입퇴장 시간 뒤바뀜, 관리자 사이트 기준 사담 · 마방 자리 부족 · 마감이 나옵니다
4. **사담 식사 · 몽몽마방 식사 · 프로그램(개별) · 프로그램(시간)**은 처음에 접혀 있습니다. 버튼 4개를 누르면 아래에 펼쳐지고, 다시 누르면 접힙니다. 값이 들어간 묶음은 버튼이 초록색이 되고 내용이 요약됩니다 (예: `사담 식사 1부 35명`, `차방 대관 2시간`). 펼친 묶음 아래에 **방문일의 예약 현황**(이 도우미에 저장된 예약 + 관리자 사이트)이 나오고, 칸에 커서를 두면 그 칸을 이미 쓴 업체가 보입니다
   - **프로그램(개별)** (인원 단위): 요가 · 가가 바우처. **프로그램(시간)** (1시간 단위): 차방 대관 · 당두봉갈 대관 · 동행 도슨트 · 세미나 도슨트
   - 견적서 사이트 품목 리스트에 단체(개별) · 단체(시간) 품목이 새로 추가되면 해당 묶음에 칸이 자동으로 생깁니다. 시트에 열이 없는 프로그램(세미나 도슨트 · 새 품목)은 비고 칸에 `추가 프로그램 세미나 도슨트 2`로 저장
   - 견적서로 넘길 때: 요가 → 요가프로그램(단체), 가가 바우처 → 음료쿠폰(가가빈빈), 차방 · 당두봉갈 대관 → 대관, 동행 도슨트 → 해설사도슨트, 세미나 도슨트 → 세미나 (시간 수 = 수량)
   - 예전 칸(티하우스 명상 · 가야금 · 유루 캐빈)은 입력 칸만 없앴고 저장된 값은 그대로 남습니다 (보고 · 엑셀의 기타 프로그램)
5. 오른쪽 **통화 메모**에는 칸에 없는 특이사항(휠체어, 요청사항 등)을 적습니다. 예약 칸을 자동으로 채우지는 않습니다
6. 끊기 전에 **확인 문구**를 읽어 줍니다
7. **Ctrl+S** 저장 → **Alt+N** 새 통화

## 입력 방식

- **단체명 · 담당자 성함 · 영업 담당**: 칸에 들어가면 항상 한글부터. 컴퓨터 입력기가 영문 상태여도 두벌식 한글로 들어갑니다. 영어는 **한/영 키**, Shift+Space, 또는 위쪽 **한** 버튼(→ **A**)
- **이메일**: 항상 영어. 입력기가 한글이어도 누른 자판 글자로 들어갑니다 (붙여넣은 한글도 자판 글자로 바뀜)
- **연락처**: 빈 칸을 누르면 `010-`이 들어가고, 숫자를 치면 `-`가 자동으로 들어갑니다 (`010-1234-5678`, `053-987-6543`, `02-1234-5678`). 내선 번호면 `010-`을 지우고 치면 됩니다 (`1234`)
- **입장**은 필수, **퇴장**은 선택
- **결제**: 세금계산서 · 결제링크 · 현장 결제 · 미정 중에서 고릅니다. **미정**이면 **결제 연락 예정일**(언제 알려주기로 했는지) 칸이 나오고 필수가 됩니다
- **미정 항목 입력 기한**: 미정 체크가 하나라도 있을 때만 맨 위 예약 단계 줄 오른쪽에 나타납니다. 기본값은 방문일 전주 목요일(방문일을 바꾸면 따라 바뀜, 직접 고치면 그대로). 미정 체크를 모두 풀면 기한도 지워집니다. 확인 문구에 "아직 정해지지 않은 관람 인원 · 차량 대수는 12월 3일까지"로 들어갑니다
- **특별 할인 안내**: 특별 할인 인원을 넣으면 고객님께 확인 문구 아래에 할인별 인원 · 할인율 · 지참할 증빙과 "가장 큰 할인 하나만 · 증빙 없으면 할인 어려움" 안내가 붙습니다
- **미정 체크**: 업체 · 방문일 · 관람 인원 · 입장 · 차량 입력칸 오른쪽 끝의 ☐미정. 체크하면 물어볼 것에 노란색(미정)으로 표시되고, 비고 칸에 `미정 체크 관람 인원, 차량 대수`로 저장
- **인원 변경 · 입장문 · 현장 재결제**: 관람 인원 옆 인원 변경 "가능성 있음" 체크, 입장 옆 입장문(치허문 · 곡신문 · 미정), 결제 옆 현장 재결제 "재결제 있음" 체크(결제 방식이 **결제링크일 때만** 켜짐). 결제가 현장 결제이거나 현장 재결제가 있으면 전산 비고에 "사유원 · 신라 금액 현장결제 필요"가 들어갑니다
- **새 통화**: 맨 위 초록 헤더의 흰 버튼 (Alt+N)
- **식사 칸**: 사담 · 몽몽마방 인원 칸을 누르면 비어 있을 때 방문 인원이 먼저 들어가고 선택된 상태라 바로 고쳐 쓸 수 있습니다
- **예약 내용 아래 버튼 4개**: 저장 · 견적서 발급 · 거래명세서 발급 · 내용 텍스트 복사 (회색 띠로 위아래 내용과 분리)
- **단체예약 목록** (헤더 버튼 → 팝업): 견적서 · 거래명세서 열에 발행 / 요청 · 미발행 표시. **삭제**를 누르면 사유를 목록에서 골라(기타는 직접 입력) 삭제하고, 사유는 그 예약의 수정 기록에 남습니다 (시트 줄은 지우지 않고 삭제 표시). **엑셀로 내려받기** 버튼으로 지금 고른 구분(전체 · 상담 · 가예약 · 공식예약 · 전산 미등록)의 예약을 방문일 순으로 엑셀 파일(`사유원_단체예약현황_YYYYMMDD.xlsx`) 하나로 내려받습니다. 엑셀 메인 시트 열 순서 + 담당자 · 입장문 · 인원 변경 · 현장 재결제 · 미정 · 특별 할인 · 통화 메모
- **내용 텍스트 복사** (카카오톡 보고용): `[단체예약 보고] 단체명`으로 시작해 예약 단계 · 방문일 · 인원 · 입장 · 차량 · 담당자 · 식사 · 프로그램 · 결제 · 특별 할인 · 예상 금액(사유원/신라) · 서류 요청 · 미정 항목 · 통화 메모 · 남은 과업 · 영업 담당을 한 번에 복사
- **결제 방식별 복창 안내**: 세금계산서(사업자등록증 · 발행 이메일 · 발행일), 결제링크(결제 시점 · 현장 법인카드 재결제 여부), 현장 결제(인원 변경 어려움 안내 · 인원 확정일)를 고객님께 확인 아래에 붙입니다
- **견적서 · 거래명세서 요청**: 결제 줄의 "견적서 요청" · "거래명세서 요청" 체크. 체크했을 때만 고객님께 확인 문구에 "견적서와 거래명세서는 (이메일)로 보내드리겠습니다"가 들어가고, 추후 과업에 **견적서 발급** · **거래명세서 발급**이 생깁니다. 과업의 버튼을 누르면 견적서 사이트가 그 문서 종류로 채워져 열리고, 거기서 **출력**하면 PDF · 엑셀이 구글 드라이브 **사유원 단체예약 서류** 폴더에도 저장되어 과업에 링크가 붙고 완료로 바뀝니다 (도우미에 팀 비밀번호가 기억된 같은 브라우저에서)
- **전산 예약 수정**: 전산 예약 과업을 체크한 뒤 인원 · 날짜 · 입장 · 식사 · 프로그램 · 결제 등 전산에 들어가는 내용이 바뀌면 생기고, 바뀐 내용을 보여 줍니다. 전산을 고친 뒤 체크하면 그 내용이 새 기준이 되고, 또 바뀌면 다시 열립니다. (예약 단계 줄의 "전산 등록 완료" 체크와 자동 안내 문구는 없애고 추후 과업의 체크로 통일)
- **추후 과업** (오른쪽 열, 체크리스트 + 과업별 메모 + 직접 추가): 가예약 · 공식예약 → **전산 예약**(전산 비고 문구: 입장 시각 · 입장문, 인원 변경 여부, 현장결제면 사유원/신라 금액, 통화 메모. 붙여넣은 뒤 예약이 바뀌면 "다시 복사" 표시), 세금계산서 → **세금계산서 발행**(발행 요청 문구, 사유원 = 관람 금액 · 신라 = 관람 외 전부), 결제링크 → **결제 확인**(다음날부터 이 창을 열면 알림 창. 입금 확인함 / 열기). 저장된 예약에서는 체크 · 복사가 바로 저장. 과업은 수정 기록 칸에 함께 저장(시트 열 추가 없음)
- **사업자등록증 올리기** (세금계산서 발행 과업 안): 사진 · PDF(10MB 이하)를 올리면 Apps Script가 시트 주인의 구글 드라이브 **사유원 단체예약 서류** 폴더에 `방문일 단체명 사업자등록증` 이름으로 저장하고, 링크를 과업에 남깁니다. 파일은 비공개라 팀원이 열려면 그 폴더를 팀원 구글 계정에 공유해 두세요. 처음 한 번: Apps Script 코드 교체 → 함수 목록에서 `setupUpload` 실행(드라이브 권한 승인) → 새 버전 배포
- **통화 메모**: 예약 내용 열 맨 아래. 전산 비고 문구에 들어갑니다
- **수정 기록**: 저장할 때마다 바뀐 항목(예: `관람 인원 30 → 35`)을 시각 · 헤더의 영업 담당 이름과 함께 남기고, 오른쪽 열 추후 과업 아래 **수정 기록** 상자에 최근 것부터 보여 줍니다. 시트 맨 끝 **수정 기록** 열에 저장 (Apps Script 코드 교체 · 새 버전 배포 필요)
- 시트에는 열을 늘리지 않고 결제 칸에 `미정 (연락 2026-11-20)`, 비고 칸에 `미정 항목 입력 기한 2026-11-25`로 함께 적습니다 (Apps Script 다시 배포 필요 없음)
- **관람 인원**: 숫자와 `+`만 (`42+2`). **차량**: 차종(버스 · 승용 · 혼합 · 미정)을 고르고 대수는 숫자만. 혼합이면 버스 · 승용 대수를 따로 (`혼합 (버스 1대 + 승용 2대)`), 미정이면 물어볼 것에 노란색(미정)

`index.html`의 `SHARED_URL`에 Apps Script 웹 앱 주소가 있으면 모든 예약이 구글 시트 `calls` 시트에 한 줄씩 저장되어 모두가 같은 목록을 봅니다. 주소가 비어 있으면 각자 브라우저에만 저장됩니다.

- 인터넷이 끊기거나 비밀번호를 넣기 전에 저장한 것은 브라우저에 모아 두었다가 연결되면 올립니다 (맨 위 표시: "연결 안 됨 · n건 대기")

## 관리자 사이트(admin.sayuwon.com) 자동 가져오기

Apps Script가 15분마다 관리자 사이트에 로그인해서 두 가지를 가져옵니다.

- **사담 · 마방 현황**: 사담 런치1부 · 런치2부 · 디너, 몽몽마방 사유의 밥상의 날짜별 정원 · 현재 인원 · 팀 수 (이번 달부터 4개월). 사담 · 마방 칸 아래 현황에 `관리자 사이트 · 사담 런치1부 49/57명 · 10/19팀 · 남은 8명`처럼 나오고, 마감이면 빨간색
- **15명 이상 예약**: 오늘부터 180일 안의 예약 완료 건 중 15명 이상이면 목록에 **전화 필요**로 들어갑니다 (예약자 · 연락처 · 방문일 · 인원 · 상품 · 관리자 예약번호가 미리 채워짐). 열어서 전화로 받은 내용을 채우고 저장하면 표시가 없어집니다. 같은 예약은 관리자 예약번호로 한 번만 들어갑니다
