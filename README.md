# 사유원 단체 예약 접수 및 관리 도우미

단체예약 전화를 받으면서 예약 칸을 채우고, 물어볼 것 · 다시 확인할 것 · 고객님께 읽어 드릴 확인 문장 · 가격을 바로 보여 줍니다. 저장한 예약은 팀 전체가 구글 시트로 함께 보고, 전산 등록 · 견적서 · 세금계산서 · 결제 확인 같은 뒷일은 추후 과업으로 챙깁니다.

사용: https://hyunbin5786.github.io/sayuwon-sales/

---

## 1. 화면 구성

| 위치 | 내용 |
|---|---|
| 맨 위 초록 헤더 | 한/A(입력 언어) · **영업 담당**(내 이름) · 통화 시간 · **＋ 새 통화** · **단체상담 입력** · **단체예약 목록** · **마이페이지** |
| 1열 **예약 내용** | 제목 줄 오른쪽에 **미정 항목 입력 기한**, 회색 칸에 **예약 단계**(상담 · 예약접수)와 버튼 4개(**저장 · 견적서 · 거래명세서 · 텍스트 복사**), 아래로 기본 · 담당자 · 방문 칸, 식사 · 프로그램 버튼 4개, 맨 아래 **통화 메모** |
| 2열 **통화 중 확인** | 물어볼 것 · 다시 확인할 것 · **고객님께 확인**(읽어 드릴 문장) · **가격표** |
| 3열 | **추후 과업**(체크리스트) · **수정 기록** |

헤더는 문제가 있을 때만 상태를 보여 줍니다 (예: `연결 끊김 · 2건 대기 · 다시 시도 중`). 정상일 때는 아무것도 표시하지 않습니다.

## 2. 쓰는 순서

1. 헤더 **영업 담당**에 이름을 한 번 적습니다. 이 컴퓨터에 기억되고, 새 예약의 담당 · 수정 기록 · 마이페이지가 이 이름으로 정해집니다
2. 전화를 받으며 **예약 내용** 칸을 채웁니다. 입력을 시작하면 통화 시작 시각이 찍힙니다
3. 가운데 **물어볼 것**을 보며 빠진 것을 묻습니다. 받은 항목은 초록, 미정으로 체크한 항목은 노랑, 아직 안 받은 항목은 빨강입니다 (마우스를 올리면 물어볼 문장)
4. 끊기 전에 **고객님께 확인** 문장을 읽어 드립니다
5. **저장**(Ctrl+S) → **＋ 새 통화**(Alt+N)

## 3. 예약 내용 칸

### 예약 단계
- **상담**: 결제 방식을 고르기 전. 일부만 적어도 저장됩니다
- **예약접수**: 결제 방식을 고름(미정 포함). 사유원 전산에 등록해야 하며 추후 과업에 **전산 예약**이 생깁니다
- 결제 칸을 보고 자동으로 고르고(점선 테두리), 버튼으로 직접 바꿀 수 있습니다. 예전에 가예약 · 공식예약으로 저장한 예약은 예약접수로 보입니다

### 기본 · 담당자 · 방문
- **업체 · 담당자 성함 · 영업 담당**: 칸에 들어가면 항상 한글부터 (입력기가 영문이어도 두벌식 한글). 영어는 한/영 키, Shift+Space, 또는 헤더의 **한** 버튼
- **이메일**: 항상 영어 (입력기가 한글이어도 누른 자판 글자로)
- **연락처**: 빈 칸을 누르면 `010-`, 숫자를 치면 `-` 자동 (`010-1234-5678`, `053-987-6543`, `02-1234-5678`). 내선이면 `010-`을 지우고 입력
- **담당자**: **+ 담당자 추가**로 여러 명, × 로 빼기. 첫 담당자의 성함 · 연락처 · 이메일이 필수
- **방문일**: 칸을 누르면 **달력**이 먼저 열립니다. 달력이 열린 뒤 칸을 **한 번 더 누르면** 글자로 직접 고칠 수 있습니다 (숫자를 치기 시작해도 바로 직접 입력). `2026-12-05` · `2026.12.5` · `20261205` · `12/5` · `1205` · `12월 5일` 모두 되고, 연도가 없으면 올해(지났으면 내년). 칸에는 `2026-12-05 (토)`처럼 요일까지 보입니다
- **관람 인원**: 숫자와 `+`만 (`42+2`). 옆에 **인원 변경 가능성 있음** 체크
- **입장**(필수) · **퇴장**(선택)은 **24시간 표시 시각**입니다. 숫자만 치면 `:`가 자동으로 들어가고(1330 → 13:30), 칸을 나가면 `09:30` 형식으로 맞춥니다. 입장 칸이 비어 있을 때 누르면 기본 **12:00**이 들어갑니다(선택된 상태라 바로 고쳐 쓰기). 시각이 아니면 다시 확인할 것에 표시
- **입장문**: 치허문 · 곡신문 · 미정
- **차량**: 차종 버스 · 승용 · 혼합 · 미정. **혼합**이면 버스 · 승용 대수를 따로 (`혼합 (버스 1대 + 승용 2대)`), **미정**이면 물어볼 것에 노란색
- **결제**: 세금계산서 · 결제링크 · 현장 결제 · 미정
  - **미정**이면 **결제 연락 예정일** 칸이 나오고 필수
  - **현장 재결제 있음**은 결제링크일 때만 켜집니다 (현장에서 법인카드로 다시 결제하는 경우)
- **Enter** = 다음 칸

### 미정 체크와 입력 기한
- 업체 · 방문일 · 관람 인원 · 입장 칸의 ☐**미정**은 칸 이름 줄 오른쪽 끝에 있습니다 (기본 줄 업체 · 방문일 · 관람 인원 · 인원 변경 4칸은 한 줄). 차량은 차종에서 **미정**
- 미정이 하나라도 있으면 제목 줄 오른쪽에 **미정 항목 입력 기한**이 나옵니다. 기본값은 **방문일 전주 목요일** (방문일을 바꾸면 따라 바뀜)
- 입력 기한은 **전주 목요일까지**입니다. 그보다 늦은 날로 바꾸거나, 늦은 기한 그대로 저장하면 **사유를 적는 팝업**이 뜹니다 (**전주 목요일로 되돌리기**도 가능). 사유는 비고 칸 `입력 기한 늦춘 사유 …`와 수정 기록에 남고, 다시 확인할 것에도 보입니다
- 미정 체크를 모두 풀면 기한 · 사유도 지워집니다

### 식사 · 프로그램 (버튼 4개, 처음엔 접힘)
- **사담 식사**(1부 · 2부 · 디너) · **몽몽마방 식사**(런치 · 디너 · 메뉴) · **개별 프로그램** · **시간 프로그램**
- 누르면 펼쳐지고, 값이 있으면 버튼이 초록 + 내용 요약. 펼친 묶음 아래에 **방문일의 예약 현황**(이 도우미에 저장된 예약 + 관리자 사이트 사담 · 마방 정원)이 나오고, 칸에 커서를 두면 그 칸을 쓴 업체가 보입니다
- 식사 칸이 비어 있을 때 누르면 방문 인원이 먼저 들어갑니다 (선택된 상태라 바로 고쳐 쓰기)
- **개별 프로그램**(인원 단위): 요가 · 가가 바우처
- **시간 프로그램**(1시간 단위): 차방 대관 · 당두봉갈 대관 · 동행 도슨트 · 세미나 도슨트
- 견적서 사이트 품목 리스트에 **단체(개별) · 단체(시간)** 품목이 새로 생기면 해당 묶음에 칸이 자동으로 추가됩니다
- 예전 칸(티하우스 명상 · 가야금 · 유루 캐빈)은 입력 칸만 없앴고, 저장된 값은 보고 · 엑셀의 '기타 프로그램'으로 남습니다

### 통화 메모
- 예약 내용 열 맨 아래. 칸에 없는 특이사항(휠체어, 요청사항 등)을 적습니다. 전산 비고 문구에도 들어갑니다

## 4. 통화 중 확인 (가운데 열)

- **물어볼 것**: 필수 항목 (초록 = 받음, 노랑 = 미정, 빨강 = 아직)
- **다시 확인할 것**: 지난 날짜, 입퇴장 시간 뒤바뀜, 입력 기한이 방문일 · 전주 목요일보다 늦음, 예약접수인데 전산 미등록, 특별 할인 증빙 안내, 관리자 사이트 기준 사담 · 마방 자리 부족 · 마감
- **고객님께 확인**: 읽어 드릴 문장. 업체명은 `<업체명>`으로 들어갑니다
  > 확인차 말씀드리겠습니다. <가나초등학교> 단체로 12월 5일 토요일에 방문하십니다. 12:00에 치허문으로 도착하실 예정입니다. 인원은 총 25명이고, 버스 1대, 승용차 2대로 오십니다. 식사는 사담 1부 25명으로 준비하겠습니다. 프로그램은 요가 20명으로 진행합니다. 결제는 세금계산서로 진행하겠습니다. 이대로 예약 도와드리면 될까요? 저희가 입장 전날에 전화드리면서 다시 안내드리겠습니다.
  - 마지막 멘트는 항상 "저희가 입장 전날에 전화드리면서 다시 안내드리겠습니다."
  - 그 아래에 **결제 방식별 안내**(세금계산서: 사업자등록증 · 발행 이메일 · 발행일 / 결제링크: 결제 시점 · 현장 법인카드 재결제 / 현장 결제: 인원 변경 어려움 · 인원 확정일)와 **특별 할인 안내**(인원 · 할인율 · 지참할 증빙)가 붙습니다
  - 견적서 · 거래명세서를 발급하면 "견적서는 (이메일)로 보내드리겠습니다"가 들어갑니다

### 가격표
- **선택한 항목**: 방문일 · 관람 인원과 고른 식사 · 프로그램으로 품목 · 수량 · 단가 · 할인 · 금액 · **예상 합계**. 견적서 발급과 같은 계산입니다
- **관람권**: 방문일이 토 · 일 · 공휴일이면 **주말/공휴일**, 아니면 **평일**. 입장 시각이 **13:00 이후면 13~18시 관람권**, 그 전이거나 모르면 9~18시 관람권
- **공휴일**: 2026 ~ 2027년 공휴일 · 대체공휴일 · 선거일을 코드(`HOLIDAYS`)에 넣어 두었습니다. 임시공휴일이 생기거나 2028년이 되면 추가해야 합니다
- **할인**: 관람 인원 20명 미만 **사전예약 5%**, 20명 초과 **단체예약 10%** (20명은 5%). **관람 · 사담 런치(1부 · 2부)에만** 적용
- **특별 할인 인원**: 간송미술관 제휴 15% · 국가유공자 30% · 군위 주민 50% · 대구대교구 신부 · 수녀 · 신학생 무료. 단체 할인과 비교해 **큰 쪽 하나만** 적용. 비고 칸에 `특별 할인 간송 3, 군위 주민 2`로 저장
- **전체 가격표 보기**: 관람 · 관람+식사 · 식사 · 단체 프로그램의 평일 · 주말 가격
- 가격과 품목은 **견적서&거래명세서 사이트**에서 그때그때 읽어 옵니다 (그 사이트의 기본 품목, 품목 관리에서 바꾼 가격 · 숨김 · 추가 품목 반영). 불러오지 못하면 마지막으로 받은 가격

## 5. 버튼 4개 (예약 단계 줄)

- **저장** (Ctrl+S): 구글 시트에 저장. 바뀐 내용이 수정 기록에 남습니다
- **견적서 · 거래명세서**: 누르면 추후 과업의 **견적서 발급 · 거래명세서 발급**이 완료로 체크되고(시각 기록) 저장된 뒤, 견적서&거래명세서 사이트가 새 탭으로 열려 자동으로 채워집니다. 발급한 버튼은 초록 + 모서리 ✓, 다시 누르면 다시 발급
  - 채워지는 것: 수신 = 업체, 수신 담당자 = 첫 담당자, 발신 = 영업 담당, 이용일 · 인원, 품목(관람권 · 사담 · 몽몽마방 · 프로그램), 할인
  - 프로그램 → 견적서 품목: 요가 → 요가프로그램(단체), 가가 바우처 → 음료쿠폰(가가빈빈), 차방 · 당두봉갈 대관 → 대관, 동행 도슨트 → 해설사도슨트, 세미나 도슨트 → 세미나 (시간 프로그램은 시간 수 = 수량)
  - 그 사이트에서 출력한 PDF · 엑셀은 드라이브에 저장되고 링크가 과업에 붙습니다
  - 고객 정보가 주소에 남지 않도록 두 사이트가 함께 쓰는 브라우저 저장소로 넘깁니다
- **텍스트 복사** (카카오톡 보고용): `[단체예약 보고] 단체명`으로 시작해 예약 단계 · 방문일 · 인원 · 입장 · 차량 · 담당자 · 식사 · 프로그램 · 결제 · 특별 할인 · 예상 금액(사유원/신라) · 서류 · 미정 항목 · 통화 메모 · 남은 과업 · 영업 담당을 한 번에 복사

## 6. 추후 과업 · 수정 기록 (오른쪽 열)

### 추후 과업 (체크 + 과업별 메모 + 직접 추가)
| 과업 | 생기는 때 | 내용 |
|---|---|---|
| **전산 예약** | 예약접수 | 전산 비고 문구(입장 시각 · 입장문, 인원 변경 여부, 현장결제면 사유원/신라 금액, 통화 메모)와 복사 버튼. 붙여넣은 뒤 예약이 바뀌면 "다시 복사" 표시 |
| **전산 예약 수정** | 전산 예약을 체크한 뒤 인원 · 날짜 · 입장 · 식사 · 프로그램 · 결제 등이 바뀜 | 바뀐 내용 목록. 체크하면 새 기준이 되고 또 바뀌면 다시 열림 |
| **견적서 발급 · 거래명세서 발급** | 버튼을 누름 | 발급 시각, 출력 파일 링크 |
| **세금계산서 발행** | 결제 = 세금계산서 | 발행 요청 문구(사유원 = 관람 금액, 신라 = 관람 외 전부) + **사업자등록증 올리기**(사진 · PDF 10MB 이하 → 드라이브 `사유원 단체예약 서류` 폴더) |
| **결제 확인** | 결제 = 결제링크 | 다음날부터 이 창을 열면 **결제 확인할 예약** 팝업 (입금 확인함 / 열기) |

### 수정 기록
- 저장할 때마다 바뀐 항목(예: `관람 인원 30 → 35`)을 시각 · 고친 사람(헤더의 영업 담당)과 함께 남기고, 최근 것부터 보여 줍니다
- **담당이 아닌 사람이 남의 예약을 고치면** 저장 뒤 **담당자에게 보고해 주세요** 팝업이 뜹니다. 바뀐 내용이 담긴 보고 문구(`[단체예약 수정 보고] …`)를 **복사**해 카카오톡으로 보내면 됩니다. 그 수정은 담당자의 마이페이지에도 표시됩니다

## 7. 단체예약 목록 (헤더 버튼 → 팝업)

- 탭: 전체 · 상담 · **예약접수**(처음 열면 이 탭) · 전산 미등록
- 정렬: **방문일 순**(기본, 가까운 날부터) · **접수 순**(최근 접수부터). 고른 정렬은 이 컴퓨터에 기억
- 열: 방문일 · 단계 · 업체 · **담당자**(`김민수(010-1111-2222)`, 여러 명이면 쉼표) · 인원 · 입퇴장 · 식사 · 견적서 · 거래명세서(발행 / 요청 · 미발행) · **영업 담당**(파란 열) · 접수 · 삭제
- 줄을 누르면 그 예약을 불러옵니다. 닫기는 오른쪽 위 **×**, Esc, 바깥 누르기
- **삭제**: 사유를 목록에서 고르고(기타는 직접 입력) 삭제. 사유는 수정 기록에 남고, 시트 줄은 지우지 않고 삭제 표시만
- **엑셀로 내려받기**: 지금 탭 · 정렬 그대로 `사유원_단체예약현황_YYYYMMDD.xlsx`
- **관리자 사이트에서 지금 가져오기**: 아래 자동 가져오기를 바로 실행

## 8. 마이페이지 (헤더 버튼 → 팝업)

헤더 **영업 담당** 이름과 같은 예약만 모아 봅니다. 버튼의 빨간 표시: `연락 n`(오늘 연락할 미정 항목) · `수정 n`(남이 고친 기록)

3열로 나란히 보여 줍니다 (좁은 화면에서는 위아래로). 열마다 따로 스크롤됩니다.

| 1열 | 2열 | 3열 |
|---|---|---|
| **방문 예정** (방문일 순 카드: 방문일 · 단계 · 업체 · 인원 · 담당자(전화) · 미정 항목과 기한 · 견적서/거래명세서 · 남은 과업 수). **지난 방문도 보기**로 전체 | **다른 사람이 수정한 내 예약**(누가 · 언제 · 무엇을, **모두 확인함**으로 지움) + **연락할 미정 항목**(입력 기한이 오늘이거나 지난 예약과 담당자 연락처) | **남은 과업** (예약별로 아직 체크 안 한 과업) |

- 카드를 누르면 그 예약을 불러옵니다

## 11. 공유 저장 (구글 시트 · Apps Script)

`index.html`의 `SHARED_URL`(Apps Script 웹 앱 주소)로 모든 예약이 구글 시트 `calls` 시트에 한 줄씩 저장되어 모두가 같은 목록을 봅니다.

- **팀 비밀번호**가 맞아야 읽고 쓸 수 있습니다. 비밀번호는 Apps Script **스크립트 속성 `PASSCODE`**에만 있고 이 저장소에는 없습니다. 처음 한 번 넣으면 그 브라우저에 기억됩니다
- 인터넷이 끊긴 사이 저장한 것은 브라우저에 모아 두었다가 15초마다 다시 올립니다
- 창으로 돌아올 때와 1분마다 최신 목록을 다시 불러옵니다
- 시트에 열을 늘리지 않으려고 일부 값은 기존 칸에 함께 적습니다
  - 결제 칸: `미정 (연락 2026-11-20)`
  - 비고 칸(` / `로 구분): 미정 체크 · 미정 항목 입력 기한 · 입력 기한 늦춘 사유 · 전산 등록 · 입장문 · 인원 변경 · 현장 재결제 · 견적서/거래명세서 요청 · 특별 할인 · 추가 프로그램(세미나 도슨트 · 새 품목)
  - 수정 기록 칸: `{h: 수정 기록, tasks: 추후 과업}` (JSON)
  - 담당자가 여러 명이면 고객 담당자 · 연락처 · 이메일 칸에 같은 순서로 ` / `
  - 통화 구분 칸: 상담 · 예약접수 (예전 기록은 단체예약 · 가예약 · 공식예약)
- 지우면 줄을 없애지 않고 `삭제` 칸에 일시를 적습니다

시트 열: ID · 저장 일시 · 통화 시작 · 받은 사람 · 통화 구분 · 요약 · 방문일 · 업체 · 담당 · 결제 · 차량 · 입퇴장 · 관람 · 사담 1부 · 사담 2부 · 사담 디너 · 마방 런치 · 마방 디너 · 차방 · 동행 · 당두 · 요가/명상 · 가가 바우처 · 티하우스 명상 · 가야금 · 유루 캐빈 · 고객 담당자 · 연락처 · 이메일 · 입장 · 퇴장 · 식사 여부(예전 기록) · 마방 메뉴 · 비고 · 통화 메모 · 수정 일시 · 삭제 · 수정 기록

### 설치 · 다시 배포
1. script.google.com 새 프로젝트에 `group-intake.gs`를 붙여넣고 저장

## 12. 관리자 사이트(admin.sayuwon.com) 자동 가져오기

Apps Script가 15분마다 관리자 사이트에 로그인해 (조회만) 두 가지를 가져옵니다.

- **사담 · 마방 현황**: 사담 런치1부 · 런치2부 · 디너, 몽몽마방 사유의 밥상의 날짜별 정원 · 현재 인원 · 팀 수 (이번 달부터 4개월). 식사 칸 아래 현황에 `관리자 사이트 · 사담 런치1부 49/57명 · 10/19팀 · 남은 8명`처럼 나오고, 마감이면 빨간색
- **15명 이상 예약**: 오늘부터 180일 안의 예약 완료 건 중 15명 이상이면 목록에 **전화 필요**로 들어갑니다 (예약자 · 연락처 · 방문일 · 인원 · 상품 · 관리자 예약번호를 미리 채움, 단계는 예약접수 · 전산 등록됨). 열어서 전화로 받은 내용을 채우고 저장하면 표시가 없어집니다. 같은 예약은 관리자 예약번호로 한 번만
